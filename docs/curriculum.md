  - 기울기: 시각 커서 $t$에서 $x(t)$ 접선 표시 → 기울기 값이 $v(t)$ 위 점으로 대응. $v \to a$ 동일
  - 넓이: $a(t)$ 아래 $0$–$t$ 구간 음영 → $\Delta v$ 막대로 $v(t)$ 위에 표시. $v \to \Delta x$ 동일
  - 음의 넓이: 별색 음영
  - Σ: 현재 구간 기울기 $a = \Delta v/\Delta t$, $v = v_0 + \int_0^t a\,dt$, $x = x_0 + \int_0^t v\,dt$. 대입 숫자 자릿수 = 표시된 계산이 표시된 결과를 재현하는 최소 자릿수 (Ch 2–6 공통)
- 입력: 프리셋 (등속, 등가속, 출발 후 정지, 왕복) 또는 구간별 상수 $a(t)$ 직접 그리기
- 대안: 단일 화면 구현이 복잡할 경우 미분 / 적분 두 시뮬레이션으로 분할
- 탭 2 자유낙하
  - 세로 스테이지: 공의 낙하, 높이 눈금, 속도·가속도 화살표, 0.1 s 스트로보 점 (떨어뜨리기: 구간 거리 1 : 3 : 5 : …)
  - 던지기 드롭다운: 떨어뜨리기 / 위로 10 m/s / 아래로 10 m/s, 처음 높이 5–45 m (설정)
  - $y(t)$, $v(t)$, $a(t)$ 그래프 + 탭 1과 같은 미분관계·적분관계 표시
  - 착지 순간 자동 정지
  - Σ: $a = -g$, $v = v_0 - gt$, $y = h + v_0 t - \tfrac{1}{2}gt^2$ (현재 $t$ 대입)
  - 자유물체도 토글 (주, 기본 꺼짐): 공 중심에서 $m\vec g$ 하나 (파선), 최고점 포함 비행 내내 같음. 모델에 질량 없음 → 길이 고정 (높이 범위의 0.12배 = 꺼졌을 때 $\vec a$ 길이), $\vec a$ 화살표 숨김, $\vec v$ 유지. Σ: $\Sigma F_y = -mg = ma \Rightarrow a = -g$ 추가

#### Ch 3. Vectors

- **학습 목표**: 성분 분해
- 탭 1 성분 분해
  - 2D 평면 + 축 정렬 격자, 축 위 투영 (점선), 성분 화살표, 직각삼각형
  - $\vec A$ 끝 드래그 → 벡터 변경, $A_x$·$A_y$ 끝 드래그 → 해당 성분만 변경
  - 화살표 옆 값 표시: $A$, $A_x$, $A_y$, $\theta$. 라벨끼리·화살표·축·눈금 숫자와 겹치면 법선 방향 또는 반대편으로 이동
  - 좌표축 회전 슬라이더 (0–60°, 1° 간격): 성분 변화 · 크기 $A$ 불변, 30° = 경사면 좌표 (Ch 5·6 연계)
  - 끌기 방식 드롭다운: 부드럽게 / 0.5 간격 맞춤
    - 0.5 간격 맞춤: 회전한 축의 격자점 중 가장 가까운 점, 화면 좌표를 $10^{-12}$까지 저장 → 표시 성분이 정확히 0.5의 배수 (1.49 · −2.51 같은 반올림 잔차 없음)
  - Σ: $A = \sqrt{A_x^2 + A_y^2}$, $A_x = A\cos\theta$, $A_y = A\sin\theta$. $\vec A = 0$이면 $A = 0$만
  - 끝점 범위: $(\lvert A_x\rvert + A)/2 \le 5.5$, $(\lvert A_y\rvert + A)/2 \le 5.5$ (화면 좌표 기준). 성분 끝은 지름 $OA$인 원 위 → 어떤 축 각도에서도 $A_x$·$A_y$ 끝과 손잡이가 무대 안. 축 방향은 5.5까지, 대각선 모서리는 약 4.56까지
- 탭 2 벡터 합: 평행사변형법, $\vec C = \vec A + \vec B$ 대각선
  - 화살표 옆 크기 $A$, $B$, $C$
  - 좌상단 패널: $A_x + B_x = C_x$, $A_y + B_y = C_y$ 기호와 현재 값 (A 파랑, B 주황, C 검정)
  - Σ: $C_x = A_x + B_x$, $C_y = A_y + B_y$, $C = \sqrt{C_x^2 + C_y^2}$

#### Ch 4. Motion in Two and Three Dimensions

- **학습 목표**: 포물선 운동 = x 방향 등속운동 + y 방향 등가속운동, 두 성분 독립
- 화면: 궤적 · x축 위 그림자 공 (등속) · y축 위 그림자 공 (연직 투사) 동시 이동
  - 공: 속도 $\vec v$, x 그림자: $v_x$, y 그림자: $v_y$ 화살표
  - $\vec v$와 $v_x$ 화살표가 x축 위에서 겹칠 때 (작은 발사각, 출발·착지) 위쪽 라벨을 한 줄 위로 이동 → 라벨 겹침 없음
  - y축 눈금 숫자: 축에서 14 px 왼쪽 → y 그림자 공과 겹침 없음
- 일정 시간 간격 스트로보 점: 궤적 위 + 두 축 위 → x 간격 일정, y 간격 선형 변화
- 그래프 4개
  - $x(t)$: 직선
  - $v_x(t)$: 상수
  - $y(t)$: 포물선
  - $v_y(t)$: 기울기 $-g$ 직선
- 발사각 (0–75°)과 발사 높이 (0–40 m)를 독립적으로 조절
  - 높이 $> 0$: 언덕 표시
  - 발사각 0°, 높이 $> 0$ (수평 발사): y 그림자 = 같은 높이에서 떨어뜨린 공 → 착지 시각 동일 (별도 비교 공 대신 그림자로 표현)
- 착지 순간 자동 정지 (체공 시간이 파라미터에 따라 결정)
- 파라미터: 발사각, 발사 높이 (주), $v_0$, $g$ (지구·화성·달), 스트로보 간격, 속도 화살표 (설정)
- Σ (탭 1): $v_x = v_0\cos\theta$, $v_y = v_0\sin\theta - gt$, $y = h + v_0\sin\theta\,t - \tfrac{1}{2}gt^2$, $v = \sqrt{v_x^2 + v_y^2}$ (현재 $t$ 대입)
- 자유물체도 토글 (탭 1, 주, 기본 꺼짐): 공 중심에서 $m\vec g$ 하나 (파선), 비행 내내 같음
  - 길이: 지구 $mg$ = 화면 범위의 0.12배, 화성·달은 $g$에 비례해 짧음 (최소 14 px). 모델에 질량 없음
  - 공 위 $\vec v$ 숨김 (급강하 때 $m\vec g$와 겹침), $v_x$·$v_y$ 그림자 화살표 유지, $v_x$ 라벨은 화살표 끝 오른쪽
  - $m\vec g$가 x축 눈금 숫자·축 이름에 닿는 동안 공 근처 글자 생략, 원점 0은 y 눈금 열로 이동
  - Σ: $\Sigma\vec F = m\vec g \Rightarrow a_x = 0$, $a_y = -g$ 추가
- 탭 2 등속원운동
  - **학습 목표**: 속력 일정, 속도 방향 변화 → 가속도 존재, $\vec a$는 중심 방향, $a = v^2/r$
  - 화면: 원 궤도 위 점, 접선 방향 $\vec v$, 중심 방향 $\vec a$, 반지름 $r$ 라벨. 힘 도입 전 단원 → 경로, 화살표, 수치 줄만 표시 (옆 속도 원 없음)
  - 세계 범위: 최대 반지름 3 m 기준 정사각형으로 고정 → 원이 무대 높이를 채움, 작은 $r$은 작은 원으로 비교 가능
  - 관찰: $\vec a$는 원 위 어디서나 중심 방향, 크기 $a = v^2/r$ 일정 → 방향이 계속 바뀌므로 등가속도 운동 아님
  - 옛 공유 링크의 `hodo` 값: 스키마에 없는 키라 무시, 나머지 값 유지 (테스트)
  - 파라미터: 반지름 1–3 m, 속력 1–3 m/s, 수치 줄 $v$, $a$, $T$
  - Σ: $a = v^2/r$, $T = 2\pi r/v$
  - 가속도 화살표: 작은 $a$에서 비례, 큰 $a$에서 길이 압축 (최대 $0.55r$, 라벨까지 중심 미도달), 최소 길이 보장 ($r$ = 3 m, $v$ = 1 m/s에서도 보임). 압축 사실은 ⓘ 가정에만 기재
- 탭 3 상대운동 (강 건너기)
  - **학습 목표**: 속도는 기준계에 따라 다름, $\vec v_{BG} = \vec v_{BW} + \vec v_{WG}$
  - 화면: 같은 운동을 위·아래 두 패널로 동시 표시. 위 지면 기준 (물살 무늬 이동, 배는 $\vec v_{BG}$로 이동, 속도 삼각형) · 아래 물 기준 (강둑이 $-\vec v_{WG}$로 이동, 배는 뱃머리 방향 직진, $\vec v_{BW}$만)
  - 각 패널: 강폭 20 m, 물살 무늬, 강둑 눈금, 출발점과 맞은편 지점, 배와 지나온 경로. 물·강둑선·무늬·눈금 모두 패널 전체 폭에 걸침. 우상단 제목 줄에 기준계 이름
  - 두 패널 같은 축척 (패널 높이 기준). 전체 경로가 패널 폭에 들어가면 두 패널 x 범위 공통 → $t$ = 0 출발점 위아래 정렬, 두 배의 x 차이 = $v_{WG}t$. 안 들어가면 패널마다 자기 배를 따라 강 방향 이동, 전체 경로 끝에서 멈춤
  - 벡터 색: Ch 3 벡터 합과 같음 ($\vec v_{BW}$ 파랑, $\vec v_{WG}$ 주황, $\vec v_{BG}$ 검정), 좌상단 패널에 성분식
  - 벡터 라벨: 세 화살표가 이루는 삼각형 바깥쪽, 각 화살표 중간 옆
  - 화살표 축척 4 m per m/s. 좁은 무대 (폭 < 600 px): 위 패널을 수식 패널 아래에서 시작
  - 수치 줄: $x_{BG}$ (지면 기준), $x_{BW}$ (물 기준), $y$ (공통)
  - 파라미터: 뱃머리 각 0–60°, 기본 30° (주), 배의 속력 1–3 m/s, 물살 0–1.5 m/s (설정)
  - 기본값에서 뱃머리 30° → 물살 상쇄, 맞은편 정면 도착
  - Σ: $v_{BG,x} = -v_{BW}\sin\theta + v_{WG}$, $v_{BG,y} = v_{BW}\cos\theta$, $x_{BG} = v_{BG,x}t$, $y = v_{BG,y}t$, $y = W$에서 $t = W/(v_{BW}\cos\theta)$

#### Ch 5. Force and Motion I

- **학습 목표**: 뉴턴 법칙, 관성계
- 화면 (탭 1–4): 상단 트랙 띠 · 하단 시간 그래프 (`stack` 배치)
- 제1·2법칙을 한 탭에 두면 각 법칙이 흐려짐 → 탭 분리 (사용자 요청, 2026-11-18)
- 탭 1 뉴턴 제1법칙
  - 퍽이 처음 속도 $v_0$로 출발, 수평 힘은 운동 마찰력 $f_k = \mu_k mg$ (뒤쪽 분홍 화살표 $f$)뿐
  - 마찰 계수 슬라이더 0–0.3 (주, 실행 중 변경 가능), 기본 0 → 힘 없이 등속, 스트로보 간격 일정
  - 마찰 > 0: 감속 $a = -\mu_k g$, $t = v_0/(\mu_k g)$에 $x = v_0^2/(2\mu_k g)$에서 정지. 정지 후 마찰력 0
  - 마찰만큼 밀기 토글 (주): 움직이는 동안 앞쪽 힘 $F = f_k$ → 힘 두 개, $F_\text{net} = 0$ → 마찰이 있어도 등속
  - 실행 중 마찰을 0으로 내리면 그 순간 속도로 등속
  - 그래프 $F_\text{net}(t)$ (범위 고정, 최대 마찰 2.94 N 기준), $v(t)$. 수치 줄 $f$, $F_\text{net}$, $v$
  - 축척: 트랙 = 마찰 없을 때 6 s 이동 거리 $6v_0$ → 마찰이 미끄럼 거리를 줄이는 것이 보임
  - 파라미터: 처음 속도 1–5 m/s (설정, 기본 3 m/s), 스트로보 0.5 s (설정). 퍽 1 kg, $g = 9.8$ m/s² (ⓘ). 6 s 후 자동 정지
  - Σ: 미끄러지는 동안 $f_k = \mu_k mg$, $F_\text{net} = -f_k$ (밀기: $F - f_k$). $F_\text{net} = 0$ → $v = v_0$, 아니면 $a = F_\text{net}/m$, $v = v_0 + at$. 정지 후 $f = 0$, $v = 0$
  - 자유물체도 토글 (주, 기본 꺼짐): 퍽 중심에서 $f_k$ (미끄러지는 동안), $F$ (밀기), $N$, $m\vec g$ (파선), 무게 9.8 N 기준 같은 축척. 퍽은 트랙 위에 얹힌 모습, 따로 그린 $f$·$F$·$v$ 화살표 숨김, $m\vec g$가 지나는 눈금 숫자·축 이름 생략. Σ: $\Sigma F_y = N - mg = 0$ 추가
- 탭 2 뉴턴 제2법칙
  - 마찰 없는 면, 정지한 퍽에 일정한 힘 $F$ (분홍 화살표), 속도·가속도 화살표, 0.5 s 스트로보 점 (트랙 위 속 빈 원, 축 눈금과 구분)
  - 그래프 $F_\text{net}(t)$, $a(t)$, $v(t)$. $v(t)$ 접선 기울기 → $a(t)$ 위 점 (Ch 2 미분관계 재사용)
  - 파라미터: 힘의 크기 0.5–5 N, 질량 1–5 kg (둘 다 주), 스트로보 (설정). 기본 4 N, 2 kg ($a = 2$ m/s²), 4 s 후 자동 정지
  - 축척 고정: 트랙 40 m, $a$ 0–5 m/s², $v$ 0–20 m/s = 슬라이더 최대 가속도 (5 N, 1 kg) 기준 → 힘 2배면 2배 멀리, 질량 2배면 절반. $F_\text{net}(t)$ 범위와 $F$ 화살표는 최대 힘 5 N 기준
  - Σ: $a = F_\text{net}/m$, $v = at$, $x = \tfrac{1}{2}at^2$
  - 자유물체도 토글 (주, 기본 꺼짐): 퍽 중심에서 $F$, $N$, $m\vec g$ (파선), 실행마다 $\max(mg, F)$ 기준 같은 축척 → 길이 비 $F/mg = a/g$. $F$·$v$·$a$ 화살표 숨김. Σ: $\Sigma F_x = F$, $\Sigma F_y = N - mg = 0$ 추가
- 탭 3 뉴턴 제3법칙
  - 수레 A의 오른쪽 면에 범퍼 용수철 (자연 길이 1 m, 질량 무시, 완전 탄성). 힘 = $k$ × 압축 길이 $c$, 같은 압축에서 두 수레에 동시에 작용 → $\vec F_{AB} = -\vec F_{BA}$가 입력이 아니라 결과 (사용자 피드백, 2026-11-18: 이전 판은 미는 힘 크기를 슬라이더로 직접 설정)
  - 상황 드롭다운: 충돌 (기본, A가 $v_0$로 정지한 B에 부딪힘, 0.6 s에 접촉) / 밀어내기 (정지 상태, 0.5 m 압축된 범퍼를 놓음)
  - 정확해: 질량중심 등속, 상대 좌표 $c'' = -\omega^2 c$, $\omega^2 = k/\mu$. 충돌 접촉 시간 $\pi/\omega$, 최대 힘 $v_0\sqrt{k\mu}$. 밀어내기 접촉 시간 $\pi/(2\omega)$, 최대 힘 $k c_0$
  - 힘 화살표 $\vec F_{AB}$, $\vec F_{BA}$: 힘을 받는 수레 위, 접촉면에서 바깥쪽, 같은 길이 (실행 최대 힘 기준). 속도 화살표 $v$. 트랙은 눈금 없는 선 (위치 값은 이 탭의 관심 밖)
  - 자유물체도 토글 (주, 기본 꺼짐): 각 수레 중심에서 접촉력, $\vec N$ (실선), $m\vec g$ (파선), 모든 힘 같은 축척 → 한 수레의 $\vec N$과 $m\vec g$는 평형이지만 쌍 아님, 쌍은 다른 수레에. 짝 (트랙을 누르는 힘, 지구를 당기는 힘)은 ⓘ에 기술
  - 그래프 $F$, $a$, $v$: A 실선, B 파선 → $F$는 매 순간 0 기준 대칭 (시간에 따라 변하는 혹 모양), $\lvert a_A\rvert / \lvert a_B\rvert = m_B / m_A$
  - 파라미터: 상황, A의 질량, B의 질량 0.5–5 kg (주, 기본 3 kg, 1 kg), 자유물체도 (주), A의 처음 속도 0.5–3 m/s (설정, 충돌만, 기본 2 m/s), 범퍼 강성 30–150 N/m (설정, 기본 50 N/m, 최대 압축 < 1 m 보장)
  - 기본값: 접촉 0.38 s, 최대 힘 12.2 N, 충돌 후 $v_A = 1$ m/s, $v_B = 3$ m/s. 접촉 끝 + 1.5 s 후 자동 정지
  - Σ: $F_{BA} = kc$, $F_{AB} = -F_{BA}$, $a_A = F_{AB}/m_A$, $a_B = F_{BA}/m_B$. 자유물체도 켜면 $N_A = m_A g$, $N_B = m_B g$ 추가
- 탭 4 관성계
  - 기차 안 마찰 없는 탁자 위 공 (처음에 기차와 함께 2 m/s), 지면에 말뚝
  - 기준계 드롭다운: 지면 기준 / 기차 기준. 기차 드롭다운: 등속 / 가속
  - 등속 기차: 기차 기준에서도 공 정지, $a = 0$ → 지면과 같은 법칙 (갈릴레이 불변)
  - 가속 기차, 기차 기준 (기본값): 힘 없이 공이 뒤로 가속, $a = -a_0$ → 1법칙 불성립 → 비관성계
  - 관성력 $-m\vec a_0$: 회색 파선 화살표 (설정 토글, 기본 켜짐). 지면 기준에서는 기차 위에 $\vec a_0$
  - 그래프: 선택한 기준계에서 공의 $x(t)$, $v(t)$, $a(t)$. 수치 줄 $F_\text{net} = 0$, $a$, $v$
  - 공이 탁자 뒤 끝에 닿으면 자동 정지. 기차의 가속도 슬라이더 0.5–2 m/s² (설정)
  - Σ: 지면 기준 $F_\text{net} = 0$ → $a = 0$, $v = v_0$. 기차 기준 $a' = a - a_0$, $v' = a't$, 관성력 표시 중 $ma' = -ma_0$
  - 자유물체도 토글 (주, 기본 꺼짐): 공 중심에서 실제 힘 $N$, $m\vec g$ (모든 기준계 같음, 합 0)
    - 가속 기차 기준 + 관성력 켜짐: 관성력 $-m\vec a_0$ 추가, 회색 파선 (실제 힘 아님, 장 힘·접촉력과 구분), 같은 축척 → $N + m\vec g - m\vec a_0 = m\vec a'$
    - 관성력 꺼짐: 실제 힘 합 0인데 $a' = -a_0$ → 비관성계에서 제2법칙 불성립
    - 축척: 실행마다 고정, 라벨이 무대 안·$\vec a_0$ 화살표 아래·지붕·바닥·지면 선 밖에 놓이는 최대 길이 (최대 56 px, 좁은 무대 84 px). $\vec v$·$\vec a$ 화살표 숨김
    - Σ: $\Sigma F_y = N - mg = 0$ 추가

#### Ch 6. Force and Motion II

- **학습 목표**: 정지/운동 마찰의 차이, 구심력은 새로운 힘이 아님
- 탭 1 마찰력 (`side` 배치: 스테이지 왼쪽, 그래프 오른쪽)
  - 실험 드롭다운: 수평으로 당기기 (기본) / 경사각 키우기
  - 수평으로 당기기: 2 kg 블록, 당기는 힘 $F = (4\ \text{N/s})\,t$, 자유물체도 $F$, $f_s$/$f_k$, $N$, $mg$
  - 경사각 키우기: 판을 6°/s로 기울이다 미끄러지는 순간 각 고정, 경첩에 각 호 + 경첩 왼쪽 위에 $\theta$ 값 (블록·힘 화살표와 겹치지 않음). 블록은 경첩에서 3.5 m 지점 출발, 1.6 m 미끄러진 뒤 정지
  - 그래프 $f(t)$: 정지 구간 $f_s = F$ (당기는 힘 파선과 겹침), $\mu_s N$ 도달 후 $\mu_k N$로 급락. 기준선 $\mu_s N$, $\mu_k N$ (회색 점선, 경사면에서는 $\cos\theta$로 감소). 그래프 $v(t)$
  - $F$가 시간에 비례하므로 $f(t)$ 그래프 = $f(F)$ 그래프 (가로축 눈금만 다름)
  - 경사각 키우기: $\tan\theta_c = \mu_s$에서 미끄러짐 시작 (나무 26.6°, 얼음 5.7°)
  - 재질 드롭다운 ($\mu_s$, $\mu_k$): 나무–나무 (0.50, 0.30, 기본), 강철–강철 (0.74, 0.57), 고무–콘크리트 (1.0, 0.80), 얼음–얼음 (0.10, 0.03)
  - 수치 줄 $f$, $\mu_s N$, $v$. 미끄러진 뒤 일정 시간 후 자동 정지
  - Σ: 당기기 $N = mg$, $\mu_s N$, 정지 중 $f_s = F \le \mu_s N$, 미끄러진 뒤 $f_k = \mu_k N$, $a = (F - f_k)/m$. 경사면 $N = mg\cos\theta$, $f_s = mg\sin\theta$, $\theta_c = \tan^{-1}\mu_s$, 미끄러진 뒤 $a = g(\sin\theta - \mu_k\cos\theta)$
  - 힘 화살표가 핵심 화면 → 자유물체도 토글 없음. $m\vec g$만 파선 (자유물체도 표기와 통일)
- 탭 2 원운동 (그래프 없음)
  - **학습 목표**: 관성계에서는 실제 힘의 합 = 중심 방향 $mv^2/r$. 물체와 함께 도는 회전 기준계 (비관성계)에서는 물체 정지, 실제 힘 + 원심력 = 0
  - 화면: 같은 운동을 위·아래 두 패널로 동시 표시. 위 관성계 (지면) · 아래 회전 기준계 (비관성계). 두 패널 같은 축척, 우상단 제목 줄에 기준계 이름
  - 각 패널: 왼쪽 위에서 본 모습, 오른쪽 옆에서 본 힘. 열 제목 (위에서 본 모습, 옆에서 본 실제 힘)은 위 패널에만
  - 위에서 본 모습: 원 궤도 + 지면 눈금 16개. 관성계에서는 고정, 회전 기준계에서는 $-\omega$로 (시계 방향) 회전
  - 관성계
    - 위에서 본 모습: 속도 $\vec v$, 중심을 향한 알짜힘 $\vec F_\text{net}$ (굵은 분홍)
    - 옆에서 본 실제 힘: 장력, 중력, 수직항력, 정지 마찰력만. 기울어진 힘은 파선 성분 분해, 수평 성분 $N\sin\theta$, $T\sin\theta$ 표시. 회전축 일점쇄선
  - 회전 기준계 ($t = 0$에 관성계와 일치, 각속도 $\omega = v/r$)
    - 줄 끊기 전: 물체는 출발점 $(0, -r)$에 정지, $\vec v\,' = 0$
    - 위에서 본 모습: 중심 방향 $\vec F_\text{net}$과 바깥 방향 원심력 $\vec F_\text{cf} = m\omega^2 \vec r$ 상쇄
    - 옆에서 본 힘: 실제 힘 + 원심력 → 합 0. 성분 분해 생략 (파선 성분 화살표와 관성력 구분)
  - 관성력 표시: 힘 색 분홍, 파선 화살표, 라벨 $F_\text{cf}$, $F_\text{Cor}$ → 실선 실제 힘과 구분. 관성력 설명은 정보 패널에만
  - 상황 드롭다운: 줄에 매단 공 (기본) · 평평한 커브 · 경사 커브 (설계 속력, 마찰 없음) · 원뿔 진자
  - 수치 줄 $v$, $F_{\text{net},r}$, $mv^2/r$ → 줄 끊기 전 항상 일치. $v$는 지면 기준 실제 속력: 원뿔 진자 줄 끊은 뒤 자유 낙하로 $\sqrt{v_0^2 + (g(t - t_\text{cut}))^2}$ 증가 (끝에서 1.68 → 2.64 m/s), 다른 상황은 수평 힘이 없어 일정. "구심력"은 정보 패널에서 알짜힘의 지름 성분으로 설명, 별도 힘 화살표 없음
  - 줄 끊기 (공, 원뿔 진자) / 빙판 (평평한 커브) 토글: 4분의 1 바퀴 후 중심 방향 힘 소멸
    - 관성계: 접선 방향 직진, $F_{\text{net},r} = 0$
    - 회전 기준계: 관성 경로를 $R(-\omega t)$로 변환한 경로 (회색 파선) → 바깥쪽으로 나가며 회전 반대 방향으로 휨. 위에서 본 모습에 원심력 $m\omega^2 r'$와 코리올리 힘 $-2m\vec\omega\times\vec v\,'$ (파선). 옆에서 본 힘에는 지름 방향인 원심력만
    - 반지름의 0.95배 (원뿔 진자 0.7배) 이동 후 자동 정지 → 물체·화살표·라벨이 패널 안에 머묾. 끝에서 $r'/r = 1.38$, $F_\text{cf} = 1.38\,mv^2/r$, $F_\text{Cor} = 1.9\,mv^2/r$ (원뿔 진자 1.22, 1.4)
  - 원뿔 진자 줄 끊기: 옆에서 본 그림에서 공이 자유 낙하 (중력만, 출발점에서 점선), 접선 방향 운동은 화면에 수직
  - 검증 (테스트): 줄 끊기 전 $\lvert \vec F_\text{net} + \vec F_\text{cf} \rvert < 10^{-9} F_\text{net}$ (네 상황 모두). 줄 끊은 뒤 회전 기준계 경로의 수치 미분 $\vec a\,'$ = $(\vec F_\text{cf} + \vec F_\text{Cor})/m$, 상대 오차 $< 10^{-6}$
  - 배치: 넓은 무대 → 옆에서 본 그림을 오른쪽으로 최대 $1.5r$ 이동. 좁은 무대 (폭이 축척 결정) → 패널이 내용 높이로 줄고 무대 세로 가운데 배치
  - 접선 성분 분해는 생략: 등속원운동이라 접선 성분 0
  - Σ: $mv^2/r$ (경사 커브·원뿔 진자 $mg\tan\theta$, $v = \sqrt{gr\tan\theta}$), $F_{\text{net},r}$ = 실제 힘 ($T$, $f_s$, $N\sin\theta$, $T\sin\theta$), $\omega = v/r$, $F_\text{cf} = m\omega^2 r$, $F_{\text{net},r} - F_\text{cf} = 0$. 줄 끊은 뒤 $F_{\text{net},r} = 0$, $F_\text{cf} = m\omega^2 r'$, $F_\text{Cor} = 2m\omega v'$

#### Ch 7. Kinetic Energy and Work

- **학습 목표**: 일 = $F(x)$ 그래프 넓이, $W_\text{net} = \Delta K$
- 탭 1개 (일-운동에너지 정리), 그래프는 시간축 대신 위치축이라 스테이지 안에 직접 그림
- 화면: 상단 트랙 위 블록 ($\vec F$, $\vec v$ 화살표) · 중단 $F(x)$ 그래프 · 하단 $K(x)$ 그래프, 세 띠가 $x$축 공유. 블록 위치에 세로 점선 커서
- $F(x)$ 아래 출발점–현재 위치 넓이 음영 (Ch 2 적분관계 표시 재사용: 양수 채움, 음수 빗금) + "넓이 = … J"
- $K(x)$: 지나온 경로 곡선, $K_0$ 점선, 현재 위치의 $\Delta K$ 막대 + 값 → 넓이와 항상 일치
- "넓이" 라벨·$\Delta K$ 라벨: 커서 옆에서 $F(x)$ 곡선·$K(x)$ 경로·끌기 막대와 겹치지 않는 자리 선택
- 오른쪽 막대 $W_\text{net}$ (분홍) vs $\Delta K$ (하늘) (설정 토글, 기본 켜짐). 좁은 화면에서는 그래프 아래로 이동
- 힘 드롭다운: 일정한 힘 (1 N) · 용수철 (−kx, $k = 2$ N/m, $x = -2$ m에서 정지 출발, 한 주기) · 구간별 (기본: +2 N, 0, −1.5 N) · 직접 만들기 (2 m 구간 4개, $F(x)$ 위 막대 끌기, ±2 N, 0.5 N 간격)
- 음의 일: 힘과 변위 반대 → 빗금 음영, $K$ 감소. $K = 0$이면 블록이 되돌아감
- 운동: 구간별 힘은 구간마다 등가속도 정확해 (경계 통과 시각 정확 계산), 용수철은 정확한 해 → 넓이와 $\Delta K$가 수치 오차 없이 일치
  - 경계 통과: 반올림으로 경계 몇 ulp 앞에 멈춘 블록도 바깥으로 움직이면 통과로 처리, 경계 1 nm 안의 반환점은 경계 도달로 처리 (도착 속력 $10^{-9}$ m/s 미만은 0)
  - 검증 (테스트): 직접 만들기 6561 조합 전부 $\lvert \text{넓이} - \Delta K\rvert < 10^{-9}$ J (수정 전 719 조합 0.002–0.021 J 오차). $[0, -0.5, 0, *]$는 $x = 4$ m에서 $K = 0$으로 정지 (수정 전 4.42 m까지 밀림)
- 블록 질량 2 kg, 처음 속도 1 m/s, 트랙 끝에 닿으면 자동 정지. 수치 줄 $x$, $v$, $K$
- Σ: 블록 위치의 $F$ (용수철 $F = -kx$), $W = \sum_i F_i\,\Delta x_i$ (용수철 $-\tfrac12 k(x^2 - x_0^2)$), $K = \tfrac12 mv^2$, $\Delta K = \tfrac12 m(v^2 - v_0^2)$ → $W$와 $\Delta K$ 같은 값
- 자유물체도 토글 (주, 기본 꺼짐): 블록 중심에서 $F$ (용수철 $F_s$), $N$, $m\vec g$ (파선, $mg$ = 19.6 N)
  - 실행 최대 힘 ($mg$) 기준 같은 축척 → $F$ (2–5 N)는 대부분 최소 길이 14 px. $N$·$m\vec g$는 변위에 수직 → 일 0
  - 켜면 트랙이 0.9 위로 이동 ($F(x)$ 띠와 사이 공간 확보), $\vec F$·$\vec v$ 화살표 숨김, "넓이" 라벨은 자유물체도 라벨을 피해 배치
  - Σ: $\Sigma F_x = F = ma$, $\Sigma F_y = N - mg = 0$ 추가

#### Ch 8. Potential Energy and Conservation of Energy

- **학습 목표**: 보존력의 정의 (일이 경로에 무관, 닫힌 경로 일 $= 0$), $F = -dU/dx$
- 탭 1 경로와 일 (그래프는 경로 길이축이라 스테이지 안에 직접 그림)
  - 2D 평면 위 두 점 A $(-2, 0)$, B $(2, 1.5)$ m. 1 kg 입자를 경로 따라 1.5 m/s로 옮김
  - 경로 드롭다운: 직선 · 원호 (기본) · 지그재그 · 경유점 끌기 (A → 경유점 → B, 주황 원 드래그). 사용자 자유 그리기 대신 경유점 1개
  - 선택한 경로: 주황 파선, 지나온 부분 실선. 나머지 경로는 회색
  - 힘 드롭다운: 중력 (기본) · 용수철 ($k = 2$ N/m, 자연 길이 0, 고정점 표시) · 운동 마찰력 ($\mu_k = 0.5$). 입자 위 힘 화살표
  - 오른쪽 그래프 누적 일 $W(s)$ vs 경로 길이 $s$: 모든 경로 곡선 회색 + 끝점, 선택 경로 분홍 (현재 위치까지 굵게)
  - 보존력: 모든 끝점이 $W_{AB}$ 점선 위 (경로 무관) / 마찰: 끝값이 경로 길이에 비례
  - 닫힌 경로 토글 (설정): B에서 직선으로 A 복귀 → 보존력 $W = 0$, 마찰 $W < 0$
  - 좁은 화면: 그래프를 평면 아래로 배치. 수치 줄 $s$, $W$
  - Σ: 지금까지의 일 (중력 $W_g = -mg\,\Delta y$, 용수철 $W_s = -\tfrac12 k(r^2 - r_A^2)$, 마찰 $W_f = -\mu_k mg\,s$), 경로 전체 $W_{AB}$ (중력 −14.7 J, 용수철 −6.75 J), 닫힌 경로 $\oint = 0$, 마찰은 $-\mu_k mgL$
  - 중력 화살표 파선 (자유물체도 표기와 통일). 자유물체도 토글 없음: 입자를 옮기는 힘이 모델에 없음 (ⓘ 가정에만 기재)
- 탭 2 에너지 도표 (`side` 배치)
  - 1 kg 입자, $U(x)$ 곡선 (주황) + 총에너지 $E$ 수평선 (검정), $K = E - U$ 수직 막대 (하늘)
  - 입자 위치의 접선 (회색) + $F = -dU/dx$ 화살표
  - 전환점 (빈 원 + 세로 점선), 금지 영역 $U > E$ (회색 음영), 평형점: 안정 (채운 점) / 불안정 (빈 점) + 짧은 라벨. 불안정 라벨은 언덕 위, 단 $E$ 선이 언덕 위 30 px 안을 지나면 언덕 아래로 옮겨 겹침 방지
  - 오른쪽 $K$, $U$, $E$ 막대 (도표와 같은 에너지 눈금). 시간 그래프 $K$, $U$, $E$ 와 $x(t)$
  - 퍼텐셜 드롭다운: 이중 우물 (기본, $U = (x^2 - 4)^2/8$) · 우물과 언덕 (극대 −1.5 m, 극소 1.5 m, 언덕을 넘으면 왼쪽으로 탈출). 용수철 포물선 퍼텐셜은 제외 (Ch 15 단순 조화 운동에서 $K \leftrightarrow U$ 다룸)
  - 출발 위치는 퍼텐셜마다 따로 저장 (숨은 배열 `x0s`, 기본 $-2.7$, $2.9$ m). 옛 공유 링크의 `pot=spring` → 이중 우물, 항목 3개짜리 `x0s` → 기본값
  - 출발 위치: 입자를 끌어 변경 (정지 상태 출발, $E = U(x_0)$). 기본 이중 우물 $x_0 = -2.7$ m → 왼쪽 우물 안 진동
  - 마찰 토글 (주, 바꾸면 초기화): 운동 마찰력 0.15 N (수평면 위 운동, $N = mg$ 일정 가정, ⓘ 기재) → $E$ 감소, 전환점 좁아짐, 결국 정지
  - 자동 정지: 마찰로 완전히 멈춘 순간, 또는 언덕을 넘어 그림 범위 ($\lvert x\rvert$ = 3.2 m) 끝에 닿은 순간 (끝점 속력은 $E$ 보존값). 같은 단계를 미리 계산해 종료 시각 결정, 그래프는 전체 구간 표시. 마찰 없이 우물 안에 갇히면 종료 없음 (10 s 이동 창)
  - 적분: velocity Verlet (심플렉틱) → 마찰 없을 때 60 s 동안 $\lvert \Delta E\rvert / E < 10^{-4}$ (테스트)
  - Σ: $U(x)$, $F = -dU/dx$ 닫힌 식에 현재 $x$ 대입, $K = \tfrac12 mv^2$, $E = K + U$

#### Ch 9. Center of Mass and Linear Momentum

- **학습 목표**: 운동량 보존, 운동량 보존과 운동에너지 보존의 구분
- 색: 물체 1 파랑, 물체 2 주황, 합 검정 (Ch 3 벡터 합과 같음)
- 충돌은 순간적, 사건 구동 해석해 (충돌 시각 계산, 그 사이 등속) → $p_\text{tot}$ 정확히 일정
- 탭 1 1차원 충돌 (`stack` 배치)
  - 화면: 마찰 없는 트랙 위 두 수레 (넓이 ∝ 질량), 질량중심 표식 ⊕ (트랙 바로 아래, 지나는 자리의 눈금 숫자 생략)
  - 수레가 24 px보다 작게 그려질 축척 (좁은 화면, 폭발 $E$ 큼)에서는 두 수레를 같은 배율로 확대. 접촉면 고정, 바깥쪽으로만 확대 → 접촉·용수철 간격 위치 그대로, 넓이 비 = 질량 비 유지
  - 운동량 화살표 3줄: 수레 위 $p_1$, $p_2$, 질량중심 위 $p_\text{tot}$ (같은 축척)
  - 충돌 유형 (주): 탄성 / 비탄성 (반발계수 $e$) / 완전비탄성 / 폭발 (정지 상태에서 용수철 분리)
  - 그래프 3개: $x_1, x_2, x_\text{cm}$ (질량중심은 직선) · $p_1, p_2, p_\text{tot}$ (합은 수평선) · $K_1, K_2, K_\text{tot}$ (탄성만 일정, 폭발은 증가)
  - 파라미터: 충돌 유형 (드롭다운), $m_2$ 슬라이더 0.5–4 kg (주), $m_1$ 0.5–4 kg, $v_{1i}$ 0.5–3 m/s, $v_{2i}$ −1.5–0.4 m/s, $e$ 0.05–0.95, 용수철 에너지 0.5–5 J (슬라이더), 운동량 화살표 (설정)
  - 기본값: 같은 질량 1 kg 탄성 충돌 → 속도 교환, 5 s 후 자동 정지
  - 수치 줄: $p_\text{tot}$, $K_\text{tot}$, $v_\text{cm}$
  - Σ: $p_\text{tot} = m_1 v_1 + m_2 v_2$, $K_\text{tot}$, $v_\text{cm} = p_\text{tot}/(m_1 + m_2)$, 충돌 뒤 반발계수 $e = (v_{2f} - v_{1f})/(v_{1i} - v_{2i})$ (폭발 제외)
- 탭 2 2차원 충돌
  - 화면: 마찰 없는 탁자 위 두 퍽 (퍽 2 처음 정지), 지나온 경로 점선, 질량중심 표식과 경로
  - 운동량 합 그림: $\vec p_1$ (파랑)과 $\vec p_2$ (주황)를 꼬리-머리로 이음 → 충돌 전후 같은 $\vec p_\text{tot}$ (검정)
  - 퍽 확대: 가벼운 퍽 반지름 최소 11 px (1·2 라벨 보임), 두 퍽 같은 배율 → 면적 ∝ 질량. 각 퍽을 충돌 순간 중심선 방향으로 $(f-1)R$만큼 밀어 그림 → 확대된 원판이 실제와 같은 시각·지점에서 접촉, 앞뒤로 겹침 없음. 경로·질량중심 표식도 같은 양만큼 이동
  - 충돌 유형 (주): 탄성 / 비탄성 ($e$) / 완전비탄성 (붙어서 질량중심 속도로 이동). 충격력은 두 중심을 잇는 방향 (마찰 없음)
  - 충돌 매개변수 $b$ 슬라이더 0–0.29 m, 0.01 m 간격 (주): 0이면 정면충돌. 최대값 = $m_2$ 최소 (0.5 kg)에서 $0.95(R_1 + R_2)$ → 모든 $m_2$에서 충돌 발생, URL 값도 $0.95(R_1 + R_2)$로 제한
  - 그래프 3개: $p_x$ 성분, $p_y$ 성분 (각 성분 합 수평선), $K$
  - 두 탭 공통: 그래프에서 물체 1 곡선 둘레에 연한 파랑 띠 → 색 외에 선 모양으로도 구분, 다른 곡선과 겹쳐도 보임 (같은 질량 폭발 $K_1 = K_2$, 충돌 전 $p_\text{tot} = p_1$)
  - 파라미터 (설정, 슬라이더): $m_2$ 0.5–2 kg, $v_{1i}$ 0.5–2 m/s, $e$ 0.05–0.95
  - 기본값: 같은 질량 탄성 충돌, $b = 0.2$ m → 충돌 뒤 90° 분리
  - Σ: $p_{\text{tot},x}$, $p_{\text{tot},y}$ 성분별 합, $K_\text{tot}$ (두 퍽의 속력 대입)

#### Ch 10. Rotation

- **학습 목표**: 관성모멘트의 질량 분포 의존, 회전축으로부터 거리의 제곱
- 탭 1 관성모멘트
  - 화면: 회전자 A (파랑), B (주황) 나란히, 위에서 본 2D. 각각 회전축 + 가벼운 막대 + 같은 거리 $r$의 두 질량
  - 두 회전자에 같은 토크 $\tau$ (축 둘레 곡선 화살표, 막대 끝 바깥 아래쪽 → 도는 막대·질량과 겹치지 않음) → $\alpha = \tau/I$ 비교
  - $I = \sum m r^2$ 막대: 질량 하나의 기여 $mr^2$ 두 칸, 큰 쪽이 막대 길이를 채우는 같은 축척 → $r$ 2배이면 4배
  - 그래프 2개: $\omega_A, \omega_B$ (기울기 = $\alpha$), $\theta_A, \theta_B$
  - 파라미터 (슬라이더): $r_A$, $r_B$ 0.2–1 m, 0.05 m 간격 (주), $m$ 0.5–2 kg, $\tau$ 0.1–1 N·m (설정)
  - 기본값: $r_A = 0.5$ m, $r_B = 1$ m → $I_B = 4I_A$, $\alpha_B = \alpha_A/4$. 6 s 후 자동 정지 (빠른 회전자가 15 rad/s를 넘으면 더 일찍)
  - 수치 줄: $\alpha_A$, $\alpha_B$
  - Σ: $I_A$, $I_B$ ($2mr^2$), $\alpha = \tau/I$, 실시간 $\omega = \alpha t$
- 탭 2 평행축 정리 (정적 장면)
  - 화면 왼쪽: 물체 (같은 $M = 2$ kg, $R = 0.5$ m), 질량중심 ⊕, 끌 수 있는 회전축 ⊙, 거리 $d$
  - 화면 오른쪽: $I(d) = I_\text{cm} + Md^2$ 포물선, $I_\text{cm}$ 점선, 현재 점의 $I_\text{cm}$ (파랑) + $Md^2$ (주황) 막대
  - 물체 (주): 고리 / 원판 / 막대 (길이 $2R$) → 포물선은 위아래로만 이동, 휘어진 정도 $M$ 동일
  - 회전축 끌기: 지름 방향 $-R$–$R$, 0.01 m 간격. $Md^2$ 막대가 짧으면 라벨을 점 왼쪽 위로 이동
  - $d$ 라벨: $d$ 선분 가운데 아래. 고리·원판은 테두리 안쪽 4 px 여백 안으로 밀어 넣음, 안에 들어가지 않으면 (작은 휴대폰 무대) 물체 아래
  - 수치 줄: $I_\text{cm}$, $Md^2$, $I$
  - Σ: 물체별 $I_\text{cm}$ 닫힌 식 ($MR^2$, $\tfrac12 MR^2$, $\tfrac1{12}M(2R)^2$), $Md^2$, $I = I_\text{cm} + Md^2$

#### Ch 11. Rolling, Torque, and Angular Momentum

- **학습 목표**: 미끄러짐 없는 굴림 ($v_\text{cm} = \omega R$, 병진 + 회전 운동에너지), 외부 토크 0일 때 각운동량 보존
- 탭 1 각운동량 보존 (`spin`)
  - 계 (주, 드롭다운): 줄에 매단 퍽 / 회전의자. 두 계 공통 그래프 4개: $I(t)$, $\omega(t)$, $L(t)$ (수평선), $K(t)$ → $I$와 $\omega$가 반대로 변하고 곱 $L = I\omega$ 일정
  - 수치 줄: $r$, $I$, $\omega$, $L$
  - Σ: $I = mr^2$ (의자 $I_0 + 2mr^2$), $L = I\omega$ (실시간 값, 일정), $K = L^2/2I$ (반지름 변화 중 $\tfrac12 I\omega^2 + \tfrac12 m\dot r^2$, 의자 $m\dot r^2$), 퍽 $dA/dt = L/2m$
  - (퍽) 화면: 마찰 없는 탁자 구멍을 통과하는 줄에 연결된 퍽 (위에서 본 2D), 바깥 (1 m)·안쪽 반지름 연한 원, 지나온 경로
  - (퍽) 줄의 장력 $\vec T$ (자주)는 구멍 방향 (지름 방향) → 구멍에 대한 토크 0. 속도 $\vec v$ (주홍)
  - (퍽) 장력 화살표: $T \propto 1/r^3$이 최대 37배 변함 → $T$에 비례하되 최소 30 px (ⓘ 기재)
  - (퍽) 줄 조작 (주): 당기기 (1 m → 안쪽) / 풀기 (안쪽 → 1 m) / 당겼다 풀기. 2 s 원운동 → 3 s 동안 반지름 변화 (반 코사인, 부드러운 시작·정지) → 2 s 원운동 후 자동 정지
  - (퍽) $r(t)$는 정해진 조작, 각도는 $d\phi/dt = L/(mr^2)$을 RK4로 적분 → $L$ 정확히 일정. $I = mr^2$
  - (퍽) 쓸고 간 넓이: 같은 시간 간격의 부채꼴 최근 6개를 두 색으로 번갈아 칠함 → 넓이 $L\Delta t/2m$로 모두 같음 (Ch 13 케플러 2법칙 연계). 간격은 가장 빠른 회전에서 1 rad
  - (퍽) 파라미터 (설정): 안쪽 반지름 0.3–0.8 m, 1 m에서의 각속도 1–3 rad/s, 퍽 질량 0.1–0.5 kg (슬라이더), 쓸고 간 넓이 (토글)
  - (퍽) 기본값: 당기기, 1 m → 0.5 m → $I$ 0.2 → 0.05 kg·m², $\omega$ 2 → 8 rad/s, $K$ 4배
  - (회전의자) 화면: 위에서 본 사람 (몸·머리·코로 회전 방향 표시), 두 팔 끝 아령, 아령 속도 $\vec v$
  - (회전의자) 팔 동작 (주): 오므리기 (0.8 m → 0.2 m) / 펴기 / 오므렸다 펴기. 1.5 s 회전 → 2 s 동안 변화 → 1.5 s 회전
  - (회전의자) $I = I_0 + 2mr^2$ ($I_0 = 1.5$ kg·m²), $\omega = L/I$, 각도는 RK4 적분
  - (회전의자) 파라미터 (설정, 슬라이더): 아령 질량 0.5–4 kg, 팔을 폈을 때 각속도 1–2 rad/s
  - (회전의자) 기본값: 아령 2 kg, 오므리기 → $I$ 4.06 → 1.66 kg·m², $\omega$ 1.5 → 3.67 rad/s, $K$ 2.45배
  - 계마다 동작·질량·각속도 파라미터 별도 (URL 키: 퍽 `mode`, `rIn`, `wOut`, `m`, `areas`, 회전의자 `arms`, `mDb`, `wArms`)
  - 이전 탭 2 (`s=chair`) 링크: 알 수 없는 장면 → 탭 1, 퍽으로 열림. 범위 밖 값은 기본값 (오류 없음)
- 탭 2 굴림 운동 (`roll`)
  - 화면: 같은 경사각의 평행한 레인 4개 (아래부터 상자·구·원판·고리), 맨 아래 레인은 바닥에 놓인 빗면, 도착선 점선, 빗면 발치 $\theta$ 호 (14° 미만은 글자를 바닥 아래로)

  - 동역학: 빗면 방향 뉴턴 법칙 + 질량중심에 대한 토크 + 굴림 조건 $a = \alpha R$을 2×2 연립방정식으로 풂 → $a = g\sin\theta/(1+\beta)$, $f_s = \beta Mg\sin\theta/(1+\beta)$, $\beta = I_\text{cm}/MR^2$ (고리 1, 원판 1/2, 구 2/5, 상자 0)

  - 그래프 2개

    - $K_\text{trans}$ (하늘색 실선 + 연한 띠), $K_\text{rot}$ (파랑 파선): 보는 물체. 고리는 두 선이 겹침 (띠로 구분)
  - 파라미터 (주): 경사각 슬라이더 5–40°, 1° 간격, 보는 물체 (드롭다운, 실행 중 변경 가능)
  - 기본값: 30°, 원판 → $a$ 4.90 (상자)·3.50 (구)·3.27 (원판)·2.45 (고리) m/s², 도착 0.81·0.96·0.99·1.14 s, 도착 속력 3.96·3.35·3.23·2.80 m/s
  - 수치 줄: $a$, $v_\text{cm}$, $K_\text{rot}/K_\text{trans}$ (보는 물체)
  - Σ: 보는 물체의 $a = g\sin\theta/(1+\beta)$, $f_s$, $v_\text{cm} = \sqrt{2as}$, $\omega = v_\text{cm}/R$, $K_\text{rot}/K_\text{trans} = \beta$. 상자는 $a = g\sin\theta$, $v_\text{cm}$만
  - 미끄러짐 없는 굴림에 필요한 $\mu_s \ge \beta\tan\theta/(1+\beta)$ (40° 고리에서 0.42), 구름 마찰 없음 (ⓘ 기재)
  - 자유물체도 토글 (주, 기본 꺼짐): 보는 물체 중심에서 $Mg$ (파선), $N$, $f_s$ (빗면 위쪽, 상자는 없음), 같은 축척. 켜면 보는 물체 흐리게·다른 물체 반투명, 보는 물체 이름표·속도 화살표 숨김, Σ에 $\Sigma F = Mg\sin\theta - f_s = Ma$

#### Ch 13. Gravitation

- **학습 목표**: 만유인력, 초기 조건에 따른 궤도, 탈출 조건
- 탭 1 궤도와 탈출속도
  - 화면: 지구 (고정, 실제 질량·반지름) + 탐사체 (1000 kg). 발사 지점은 지구 왼쪽, 거리 단위 $10^3$ km
  - 처음 속력 $v_0/v_\text{esc}$ (주): 슬라이더 0.3–1.4, 0.01 간격. 0.71은 정확히 원 궤도 속력 $1/\sqrt 2$, 1은 포물선
  - 발사 고도 (주): 슬라이더 1000–15000 km, 500 km 간격
  - 방향: 속도 화살표 끝 끌기 (수평 기준 −90°–90°, 1° 간격). 속력이 같으면 방향과 관계없이 $E$ 동일
  - ⓘ 탈출속도: 방향과 무관, 단 경로가 지구와 부딪히지 않을 때. 1.0배 안쪽 발사는 충돌 (1000 km에서 −21.6° 아래, 6000 km에서 −44° 아래)
  - 발사 전 예측 궤적 점선 (설정 토글), 지나온 경로 실선, 비행 중에도 발사 지점·발사 속도 화살표 (흐리게) 끌기 가능
  - 판정: 좌상단에 궤도 이름과 $E$ 부호 → 타원 ($E < 0$, 속박) / 포물선 ($E = 0$) / 쌍곡선 ($E > 0$, 탈출)
  - 탈출속도 게이지: 탐사체 둘레 점선 원 (반지름 = 현재 위치의 $v_\text{esc}$, 속도와 같은 축척) → 속도 화살표가 원 안이면 속박
  - 그래프 3개: $r(t)$ · $v$, $v_\text{esc}$ (포물선이면 두 선 일치) · $K$, $U$, $E$ ($E$ 수평선)
  - 케플러 제2법칙 (설정 토글): 주기의 1/12 간격으로 쓸고 간 부채꼴 (첫 바퀴)
  - 유효 퍼텐셜 (설정 토글, 기본 꺼짐): 우하단 에너지 도표 (켜면 궤도 상자 오른쪽에 빈 띠를 확보해 그 안에 배치, 최대 210 × 130 px → 좁은 화면에서도 궤도를 가리지 않음), $U_\text{eff}(r) = -GMm/r + L^2/2mr^2$ (주황 파선), $E$ (검정), 현재 $r$에서 $E - U_\text{eff}$ = 지름 방향 운동에너지 (하늘색 막대). 두 선이 만나는 곳 = 근지점·원지점
  - 재생 속도: 기본 4000 s/s, 긴 타원은 한 바퀴가 10 s 안에 끝나도록 주기/10 s/s (0.99 · 15000 km에서 979 s → 10 s). 주기는 속력·고도로만 정해짐 → 방향을 끌어도 불변
  - 지구 최소 크기: 반지름 6 px (경로 최저점의 0.8배 이하, 충돌 궤도는 실제 크기) → 큰 궤도에서도 지구가 보임. ⓘ에 기재
  - 정지: 타원 3바퀴 (최대 원 궤도 주기 40배, 최소 1바퀴 → 0.98 이상에서도 예측 궤적이 닫힘), 지표면 충돌 (× 표시), 탈출 궤도는 $r = 2.5r_0$ (화면 안의 원)에 닿을 때
  - 화면 범위: 같은 속력·고도의 모든 방향 (−90°–90°)에 대한 최악값. 타원은 궤도 요소 ($a$, $e$, 근지점 방향)로 구한 외접 상자의 합집합, 탈출 궤도는 $r \le 2.5r_0$ 원. 탐사체 둘레 게이지 원·속도 화살표만큼 여백 → 어느 방향으로 끌어도 탐사체·예측 궤적이 무대 안, 방향을 끌어도 확대·축소 없음
  - 속도 축척: 발사 지점 게이지 원 반지름 = $\max(0.6r_0,\ 0.09 \times \text{화면 크기})$ → 큰 궤도에서도 게이지가 보임. 게이지 원이 10 px 이하이면 $v_\text{esc}$ 라벨 생략
  - 적분: 요시다 4차 심플렉틱, 2.5 s 간격 → 100바퀴 후 $\lvert\Delta E/E\rvert < 10^{-6}$ (테스트)
  - 수치 줄: $v$, $v_\text{esc}$, $E$
  - Σ: 현재 위치의 $K = \tfrac12 mv^2$, $U = -GMm/r$ (SI 대입, GJ 결과), $E = K + U$, $v_\text{esc} = \sqrt{2GM/r}$, $v$와 $v_\text{esc}$ 대소 (<, =, >) = $E$ 부호
  - 기본값: 고도 6000 km, 0.85배 수평 발사 → 원지점 약 32000 km 타원
  - 방향 파라미터 (숨김, URL 전용): 라벨·설명 ko·en 있음
  - 자유물체도 토글 (주, 기본 꺼짐): 탐사체 중심에서 지구 쪽 $F_g = GMm/r^2$ (파선), 경로 최저점의 $F_g$ = 56 px로 실행 중 고정. $v$가 $F_g$와 30° 이내일 때만 $v$ 숨김, Σ에 $\Sigma F = F_g = ma$
- 명세 대비 변경: 초기 위치 드래그 대신 발사 고도 선택 (회전 대칭이라 방향과 거리만 의미), 에너지 막대는 $K$, $U$, $E$ 시간 그래프로 대체

#### Ch 14. Fluids

- **학습 목표**: 연속방정식 $A_1 v_1 = A_2 v_2$, 베르누이 원리
- 탭 1 벤투리관
  - 화면: 넓은 곳 (1) → 좁은 곳 (2) → 넓은 곳 (3) 원형 단면 관, 구간마다 수직 압력계 기둥, 흐름 추적 입자
  - 추적 입자: 같은 시간 간격으로 들어온 물의 열, 좁은 곳에서 간격 $A_1/A_2$배
  - 압력계 기둥 높이 $= p/\rho g$: 좁은 곳 수위 하강, 입구 수위를 점선으로 연장해 비교
  - 관 아래 표 (구간 1·2·3 열): $A$, $v$, $Av$ (일정), $p$, $\frac{1}{2}\rho v^2$, $\rho g y$, 합 (일정), 단위는 오른쪽 끝 열
  - 파라미터 (슬라이더, 즉시 반영): 단면적 비 $A_2/A_1$ 0.4–1, 유량 5–15 L/s (주), 높이 차 0–20 cm (설정, 관 기울기). 높이 차 = 구간 1 대비 구간 3 축 높이 (바깥 두 압력계 사이) → 표의 $\rho g y$ 차와 일치 (20 cm → 1.96 kPa)
  - 기본값: $A_1 = 100\ \text{cm}^2$, 비 0.5, 10 L/s → $v_1 = 1$, $v_2 = 2\ \text{m/s}$, $p_1 - p_2 = 1.5\ \text{kPa}$
  - 수치 줄: $v_1$, $v_2$, $p_1 - p_2$
  - Σ: $v_1 = Q/A_1$, $v_2 = Q/A_2$, $p_1 - p_2 = \tfrac12\rho(v_2^2 - v_1^2) + \rho g y_2$ (높이 차 0이면 둘째 항 생략), 결과 kPa
  - 입구 압력: 모든 압력계 수위가 그 지점 관 윗벽 (축 + 반지름)보다 3 cm 이상 높도록 설정, 5 cm 단위 올림 → 5733 조합 모두 수위가 관 밖에 보임 (수정 전 633 조합이 관 윗벽 아래)
  - 가정 (비압축성, 정상류, 비점성, 계기압력, 입구 압력 자동 설정, 1/4 속도 표시): ⓘ 패널에만 기재

#### Ch 15. Oscillations

- **학습 목표**: 단순조화운동 = 등속원운동의 투영, 조화진동자의 성질, 작은 각 모형의 한계 (단진자)
- 탭 1 단순조화운동
  - 화면: 좌측 기준원 위 점 + 우측 용수철-질량 (세로). 수평 투영선 하나로 둘 연결
  - 위상 공간 타원 (이전 우측 열) 제거, 사용자 요청. 두 열만 남김, 천장 0.6 → 0.54 m · 용수철 10마디 → 그림 배율 1280×800에서 약 1.7배, 390×844에서 약 1.25배
  - 원 위 점의 $\vec v$, $\vec a$, 물체의 $v$, $a$ (세로 성분) 화살표 (설정 토글)
  - 그래프 4개: $x(t)$, $v(t)$, $a(t)$, $K$·$U$·$E$ → 위상차 $90^\circ$, $a = -\omega^2 x$, $K$와 $U$ 교환·합 일정
  - 성질 확인: 진폭 변경 → 주기 불변 (등시성), $k$·$m$ 변경 → $\omega = \sqrt{k/m}$
  - 파라미터 (슬라이더): 진폭 0.05–0.3 m, 용수철 상수 5–40 N/m (주), 질량 0.2–2 kg, 감쇠비 $\zeta$ 0–0.2 (기본 0, $\zeta > 0$이면 기준원 반지름·진폭 지수 감소), 화살표 토글 (설정)
  - 수치 줄: $\omega$, $T$, $E$. 감쇠가 있으면 $\omega$와 $T$ 모두 감쇠 진동의 값 ($\omega = \omega_0\sqrt{1 - \zeta^2}$, $T = 2\pi/\omega$), ⓘ에 기재
  - Σ: $\zeta = 0$ → $\omega = \sqrt{k/m}$, $T = 2\pi\sqrt{m/k}$, 실시간 $x = A\cos\omega t$ (위상은 한 바퀴 안의 도 단위), $a = -\omega^2 x$, $E = K + U = \tfrac12 kA^2$. $\zeta > 0$ → $\omega_0$, $\omega = \omega_0\sqrt{1 - \zeta^2}$, $T = 2\pi/\omega$, $a = -\omega_0^2 x - 2\zeta\omega_0 v$, $E = K + U$
  - 자유물체도 토글 (주, 기본 꺼짐): 물체의 $F_s = mg - kx$, $mg$ (파선), 감쇠 시 $F_d$. 모두 세로 → 힘마다 열 하나 ($F_s$ 용수철 왼쪽, $mg$ 오른쪽, $F_d$ 가운데). 물체의 $a$ 화살표 숨김, Σ에 $\Sigma F = F_s - mg\ (+ F_d) = ma$
- 탭 2 단진자 (부가)
  - 화면: 실제 진자 (비선형, RK4) 하나만. 이전의 점선 추 (작은 각 모형) 제거, 사용자 요청
  - 실시간 화살표 (설정 토글, 기본 켬): 속도 $\vec v$ (접선, 주황), 접선 가속도 $a_\text{t} = -g\sin\theta$, 지름 방향 (구심) 가속도 $a_\text{r} = v^2/L$ (초록)
  - 화살표 선택 근거: $a_\text{t}$가 작은 각 근사 $\sin\theta \approx \theta$가 들어가는 바로 그 항, $a_\text{r}$는 줄 방향 → $v$와 겹치지 않음. 장력·$mg$는 맨 아래에서 한 직선에 겹치고 $T$ (주기) 기호와 충돌 → 제외
  - $a_\text{t}$는 $v$와 같은 직선 → 추 바깥쪽으로 20 px 옮겨 나란히 그림. $a_\text{r}$ 라벨은 줄 위가 아닌 옆에 둠
  - 화살표 길이: $v$와 가속도 성분 각각, 한 번 왕복 중 최댓값 = $0.45L$. $a_\text{t}$·$a_\text{r}$는 같은 비율. 추보다 짧은 화살표는 숨김, ⓘ에 기재
  - 그래프 $\theta(t)$: 실제 (파랑) + 작은 각 모형 $\theta_0\cos\omega_0 t$ (회색 점선, 그래프에만)
  - 그래프 위 범례 한 줄 (왼쪽 위): 파랑 실선 "실제 진자", 회색 점선 "작은 각 모형 $\theta_0\cos\omega_0 t$". 범례 자리 위해 세로 범위 $-1.2\theta_0$–$1.6\theta_0$ (사용자 요청, 2026-11-18)
  - 진자 아래 오차 그래프: 처음 각 $\theta_0$ (0–180°)에 따른 $\Delta T/T_0 = (T - T_0)/T_0$ (로그 눈금 0.01–300 %), 현재 각에 검은 점과 값. 1 % 회색 점선 → 22.8° 아래에서 1 % 미만, 작은 각에서 $\theta_0^2/16$ (10°: 0.191 %, 20°: 0.767 %, 90°: 18.0 %, 170°: 144 %). 세로축 제목은 아래 줄 왼쪽 (휴대폰에서 추·힘 라벨과 겹치지 않게), 자유물체도 화살표 길이는 오차 그래프 위까지로 제한
  - 무대 위쪽 경계: 처음 각 90° 이하 → 매달린 점 바로 위까지 (이전 고정 $1.05L$). 390×844에서 그림 약 1.5배
  - 파라미터 (슬라이더): 처음 각 5–170° (기본 90°), 줄 길이 0.2–2 m (주), 화살표 토글 (설정)
  - 수치 줄: 정확한 주기 $T = 4\sqrt{L/g}\,K(\sin(\theta_0/2))$ (AGM으로 계산), $T_0 = 2\pi\sqrt{L/g}$, 오차 $(T - T_0)/T_0$ (%). 이전 $T/T_0$ 대체
  - 오차 (테스트로 검증, 시뮬레이션에서 잰 주기도 일치): 10°에서 0.19 %, 30°에서 1.74 %, 90°에서 18.0 %, 150°에서 76.2 %, 170°에서 144 %. $L$과 무관
  - 수식 패널 (Σ): $T_0$, $K$, $T$, 오차에 현재 값 대입. 실시간 $a_\text{t} = -g\sin\theta$와 모형 $a_{\text{t},0} = -g\theta$, $a_\text{r} = v^2/L$ 비교 (90°에서 놓은 직후 $-9.80$ 대 $-15.4\ \text{m/s}^2$)
  - 수식 패널 유효숫자: $T$와 $T_0$의 차가 3자리 남도록 조정 (10°에서 2.01092 − 2.00709)
  - 자유물체도 토글 (주, 화살표 토글과 별개): 추 (1 kg) 중심에서 $F_T$ (줄 방향, 라벨은 줄 옆), $mg$ (파선). 켜면 $a_\text{t}$·$a_\text{r}$ 숨김 ($F_T$·$mg$와 겹침), $v$는 $mg$와 30° 이내일 때만 숨김, Σ에 $\Sigma F_\text{r} = F_T - mg\cos\theta = ma_\text{r}$

#### Ch 16. Waves I

- **학습 목표**: 진행파가 경계에서 반사 → 정상파 형성
- 탭 역할 분담: 탭 1은 반사 (입사파 + 반사파 = 합성파, 고정단·자유단), 탭 2는 정상파의 마디와 고조파 $f_n = nv/2L$
- 탭 1 반사
  - 화면: 오른쪽 끝이 경계인 줄. 입사파 파랑 점선, 반사파 주황 점선, 합성파 (실제 줄) 검정 실선
  - 오른쪽 끝 드롭다운: 고정단 (벽, 위상 반전) / 자유단 (막대 위 고리, 반전 없음)

- 설명 전략: 통계적 정의 $S = k\ln W$ 우선 → 열역학적 정의 $dS = dQ/T$로 연결
- 탭 1 자유 팽창
  - 처음에는 칸막이 뒤 왼쪽 절반에서 기체가 움직임 ($n = N$, $\Delta S = 0$). 사용자가 상자 아래 "칸막이 제거" 버튼 또는 칸막이를 눌러 제거 (재생 중·일시정지 모두, `Handle.onTap`) → 오른쪽으로 퍼짐. 초기화 (R)로 칸막이 다시 설치
  - 서로 충돌하지 않는 입자의 좌/우 분포, 상자 위에 $n$, $N - n$
  - $W(n) = \binom{N}{n}$ 막대그래프, 현재 거시상태 막대 강조 (주홍). $N \le 10$은 막대 위에 $W$ 값, $N = 1000$은 $W/W_\text{max}$ 곡선
  - $N$ 드롭다운: 4, 10 (기본), 100, 1000 (주) → 작은 $N$은 모두 왼쪽으로 복귀 관찰 가능, 큰 $N$은 사실상 불가. 본래 불연속인 값 묶음이라 드롭다운 유지
  - 입자 반지름: 상자 높이에 비례 ($N \le 10$: 0.025, $N \le 100$: 0.014, 그 이상: 0.0078 상자 높이) → 좁은 화면에서 함께 축소
  - 그래프: $n(t)$ ($N/2$ 파선), $\Delta S/k = \ln W$ ($\Delta S_\text{max}$ 파선, 최댓값 근방 요동)
  - 수치 줄: $n$, $W$, $\Delta S/k$
  - Σ: 현재 $W(n) = \binom{N}{n}$, $\Delta S/k = \ln W(n)$ (모두 왼쪽 기준 변화량), $\Delta S_\text{max}/k = \ln\binom{N}{N/2}$와 근사 $N\ln 2 - \tfrac{1}{2}\ln(\pi N/2)$, $P(n = N) = 1/2^N$ ($N$ = 1000: $9.33\times10^{-302}$)
  - 엔트로피 기준: 모두 왼쪽 ($W = 1$)을 0으로 둠, 왼쪽/오른쪽 배치만 셈 → 절대 엔트로피 아님, 표시량은 $\Delta S$ (사용자 지적, 2026-11-18). 큰 $N$에서 $\Delta S_\text{max} \approx Nk\ln 2 - \tfrac{k}{2}\ln(\pi N/2)$ → 열역학 $nR\ln(V_f/V_i)$와 일치 (ⓘ)
- 탭 2 열 흐름 (아인슈타인 고체 두 개)
  - 진동자 격자 두 개 (A 파랑, B 주황), 양자 = 점 (10개 이상은 숫자), 알짜 열 흐름이 있으면 고온 → 저온 $Q$ 화살표
  - 온도 표시: $q_\text{A}$의 1.5 s 지수 평균으로 계산 (온도계 응답 시간), 수치 줄과 $kT/\varepsilon$ 그래프 공통. 평균 $q_\text{A} = N_\text{A} q/N$에서 두 온도 같음
  - $Q$ 화살표 조건: 표시된 두 온도 차이가 큰 쪽의 30 % 초과 → 표시 (고온 → 저온), 15 % 미만 → 숨김, 변경 간격 1 s 이상, 온도 순서 역전 시 즉시 숨김 → 화살표와 수치 항상 일치, ⓘ에 기재
  - 깜빡임: 양자 20개, 작은 고체 ($N_\text{A}$ = 10, 90)에서 60 s당 약 10회 이하 (순간 온도 규칙은 수백 회)
  - 격자 사이 간격 최소 64 px (화살표 자리), B 라벨은 B 격자 오른쪽 끝에 맞춤
  - 무작위 이동: 임의의 진동자가 임의의 진동자에게 양자 하나 전달 (모든 미시상태 같은 확률)
  - $S$-$q_\text{A}$ 도표: $S_\text{A}$, $S_\text{B}$, $S_\text{tot}$ 곡선, 현재 상태 점과 $S_\text{A}$, $S_\text{B}$ 접선 띠 → 꼭대기에서 기울기 크기 같음 = 온도 같음
  - 접선 기울기: 곡선 $\ln\Omega$의 정확한 기울기 $\psi(q + N) - \psi(q + 1) = 1/(q+1) + \dots + 1/(q+N-1)$ (이전 큰 $N$ 근사 $\ln(1 + N/q)$는 곡선과 어긋남). $N_\text{A}$ = 10, $q$ = 20의 꼭대기 $q_\text{A}$ = 1에서 두 접선 기울기 차이 37 % → 12 % (꼭대기가 정수 $q_\text{A}$라 남는 차이, ⓘ 관찰에 기재)
  - ⓘ 정의 추가: 진동자 (원자 하나의 한 방향 진동), 에너지 양자 $\varepsilon = hf$, 미시상태 수 $\Omega$ (양자 $q$개를 진동자 $N$개에 나누는 방법의 수), 기울기 = $\varepsilon/kT$인 이유 ($dS = dQ/T$)
  - 곡선 라벨 $S_\text{A}$, $S_\text{B}$: 곡선 위·아래 후보 중 다른 곡선과 $S_\text{tot}$ 라벨에서 가장 먼 자리 (파라미터로만 정해져 고정)
  - 그래프: $S_\text{A}$, $S_\text{B}$, $S_\text{tot}$; $kT_\text{A}/\varepsilon$, $kT_\text{B}/\varepsilon$ ($1/\ln(1 + N/q)$, 1.5 s 평균) 수렴
  - 파라미터: 고체 A 크기 $N_\text{A}$ 10–90 (슬라이더, $N_\text{B} = 100 - N_\text{A}$, 기본 30), 양자 수 $q$ 20–200 (슬라이더, 10 간격, 기본 100) (주) · 처음 에너지 A에 모두 / B에 모두 (설정). 두 개수 모두 범위가 넓어 슬라이더 유지
  - 기본값: A에 양자 100개 → 평형 $q_\text{A} \approx 30$ (에너지가 아니라 온도가 같아짐)
  - Σ: 현재 $S_\text{A}/k = \ln\Omega_\text{A}$, $S_\text{B}/k$, $S_\text{tot}/k$ 합 (4자리), $kT/\varepsilon = 1/\ln(1 + N/\bar q)$ ($\bar q$ = 1.5 s 평균, 수치 줄과 같은 값, $\bar q = 0$이면 0)
- 탭 3 카르노 순환
  - $p$-$V$ 도표 · $T$-$S$ 도표 (직사각형, 곡선 아래 넓이 = 열) · $W$, $Q_\text{H}$, $Q_\text{C}$, $\Delta E_\text{int}$ 누적 막대, 제목 $W = Q_\text{H} - Q_\text{C} - \Delta E_\text{int}$ (J) → 순환 내내 성립 (이전 제목 $W = Q_\text{H} - Q_\text{C}$는 순환 끝에서만 성립, 단열 팽창 끝 $W$ = 2886 J, $Q_\text{H}$ = 1386 J). $\Delta E_\text{int}$ 막대는 단열 팽창 뒤 음수 (기본값 −1500 J), 순환 끝에 0
  - 이원자 기체, $T_\text{C}$ = 150 K: $V_\text{C}$ = 640 L이라 $p$-$V$ 순환이 축에 붙음. 선형 축 유지 (넓이 = 일 읽기 우선)
  - 좁은 화면: $p$-$V$ 도표가 위쪽 전체 폭, 아래에 $T$-$S$ 도표와 막대
  - 고온 열원 600 K, 저온 열원 $T_\text{C}$ 150–500 K (슬라이더, 기본 300 K) (주), 기체 단원자 / 이원자 (설정)
  - 수치 줄: $W/Q_\text{H}$, $1 - T_\text{C}/T_\text{H}$ → 같은 값 (효율 상한)
  - Σ: $Q_\text{H} = nRT_\text{H}\ln(V_\text{B}/V_\text{A})$, $Q_\text{C} = nRT_\text{C}\ln(V_\text{C}/V_\text{D})$, $Q_\text{H}/T_\text{H} = Q_\text{C}/T_\text{C}$, $W/Q_\text{H} = 1 - Q_\text{C}/Q_\text{H}$와 $1 - T_\text{C}/T_\text{H}$, 실시간 막대 1법칙 $W = Q_\text{H} - Q_\text{C} - \Delta E_\text{int}$

  - 긴 드래그: 경로가 6000점을 넘으면 오래된 절반의 점을 하나 걸러 솎음 (줄인 구간이 전하 5 cm 안을 지나면 그 점은 유지) → 시험전하가 계속 따라감. $W$는 경로와 무관하므로 그대로
  - 수치 줄: $V$ (시험전하 위치), $\Delta V$ (A 기준), $W$ (경로를 따라 $q_0\vec E\cdot d\vec s$ 수치 적분, nJ, 전하 가까운 구간일수록 잘게 나눔 → 어떤 드래그 뒤에도 $W = -q_0\Delta V$ 0.5 % 이내)
  - 관찰: 등전위선을 따라 끌면 $W \approx 0$, 가로지르면 $W = -q_0\Delta V$, 경로와 무관. 등전위선 간격이 촘촘할수록 장이 강함
  - Σ: $V = \sum_i kq_i/r_i$, $\Delta V = V - V_A$ (뺄셈 재현에 필요한 자릿수로 두 값 표기), 수치 적분 $W$, $-q_0\Delta V$ → 두 값 비교

#### Ch 25. Capacitance

- **학습 목표**: $C = \kappa\varepsilon_0 A/d$, 장에 저장되는 에너지
- 탭 1 평행판 축전기 (정적 장면, 시간 진행 없음)
  - 화면: 평행판 단면, 판 안쪽 면의 자유 전하 (채운 원), 유전체 표면 유도 전하 (빈 원), 판 사이 전기력선, 전지 $V_0$와 스위치
  - 그림 척도 (단면 폭 $\propto \sqrt{A}$ 기준): 전기력선 수 $\propto E$ (기준 판, $E_0$에서 5개), 1개 미만이면 길이 $\propto E$인 짧은 화살표 하나
  - 자유 전하 기호 수 $\propto \sigma$ (같은 척도). 판 폭을 넘으면 기호 하나 = 전하 $n$개 (1·2·5 단계), 판 위 표시 $\oplus \times n$
  - 유도 전하 = 자유 전하의 $1 - 1/\kappa$ 비율. $n = 1$이면 유도 전하 수 = 자유 전하 수 − 전기력선 수 (가우스 법칙)
  - 예: 물 + 전원 연결 → 전기력선 5개 (공기와 같음), 자유 전하 약 80배 (표시 $\times n$), 유도 전하가 98.8 % 상쇄. $d$ = 0.5 mm → 전기력선 2배
  - 좌상단 표: $C$, $Q$, $V$, $E$, $U$ 값과 기준 상태 대비 비율 $X/X_0$
  - 기준 상태 $X_0$: $A$ = 100 cm², $d$ = 1 mm, 빈 공간, $V_0$ = 12 V. 전원 분리 = 기준 상태에서 충전 후 분리 → $Q = Q_0$ 고정 (ⓘ 패널 기재)
  - 파라미터: 유전체 (공기, 종이 3.5, 유리 4.7, 물 80.4), 전원 연결 / 분리 드롭다운 (주), 판 넓이 50–200 cm² (10 cm² 간격), 판 간격 0.5–2 mm (0.1 mm 간격) 슬라이더 (설정)
  - 기본값: 유리, 전원 연결 → $U$ 4.70배
  - Σ: $C = \kappa\varepsilon_0A/d$ 대입, 연결 $Q = CV_0$·$V = V_0$ / 분리 $Q = C_0V_0$·$V = Q/C$, $E = V/d$, $U = \tfrac12CV^2$. 결과는 좌상단 표와 같은 SI 접두어·3자리, 곱·나눗셈 입력은 4자리
- 핵심 대조: 유전체 삽입 시
  - 전원 연결 ($V$ 일정) → $C$, $Q$, $U$ $\kappa$배, $E$ 그대로
  - 전원 분리 ($Q$ 일정) → $V$, $E$, $U$ $1/\kappa$배
  - 전원 분리 + 간격 확대 → $V$, $U$ 증가

#### Ch 26. Current and Resistance

- **학습 목표**: 전자 산란 → 저항, $R = \rho L/A$
- 탭 1 전자 산란과 저항
  - 화면: 도선 구간 (이온 격자 + 자유전자). 길이 $\propto L$, 높이 $\propto A$, 전자 밀도 일정
  - 드루데 모형: 충돌 직후 속력 일정·방향 무작위, 자유 시간 지수분포 (평균 $\tau \propto 1/T$), 충돌 사이 $-e\vec E$로 가속. 실행마다 새 난수 시드 (`src/core/rng.ts`)
  - 전기장 없음: 무작위 운동, 순 이동 0
  - 전압 인가: 산란 사이 가속 → 평균 드리프트. 굵게 표시한 전자 하나의 최근 2.5 s 경로, $\vec E$·$\vec v_d$ 화살표
  - 이온 진동 폭 $\propto \sqrt{T}$ (그림 효과)
- 단면 (주황 점선) 통과 알짜 전하 계수 → 전류 $I$ 측정
  - 계수에는 그린 전자의 8배를 시뮬레이션 (그림은 8개 중 1개만). 열운동 계수 잡음 $\propto 1/\sqrt N$ → 기본 도선 30 s 측정 잡음 약 1 mA, 0.1 V에서도 약 10 %
  - $\bar I$는 드리프트가 자리 잡은 뒤 ($t_0 = 4\tau$, 300 K에서 1 s, 200 K에서 1.5 s)부터 센 $\Delta Q/\Delta t$. 드리프트는 $v_d(1 - e^{-t/\tau})$로 형성 → $t = 0$부터 센 $Q/t$는 $-(\tau/t)(1 - e^{-t/\tau})$만큼 낮음 (300 K, 3 s에서 $-8.3$ %, $V/I$ 약 10.9 Ω). $t_0$부터 세면 남는 치우침 $-\tau e^{-4}/(t - t_0)$, 3 s에서 $-0.2$ % (시드 300개 평균 $-0.6 \pm 0.3$ %)
  - 그래프: $Q(t)$ (예측 직선 점선), $\bar I = \Delta Q/\Delta t$ (예측값 점선, 계수 1 s 뒤부터 표시), 30 s 측정 후 자동 정지. 그래프 범위는 예측값과 계수 잡음 상한 (양방향 통과를 독립으로 본 푸아송 근사)을 함께 포함
  - 수치 줄: 측정 $I$ (계수 2 s 전에는 –, 300 K에서 3 s), $V/I$, 예측 $\rho L/A$
  - 입자 범례: 스테이지 오른쪽 위 작은 표시, 회색 점 = 양이온, 파랑 점 = 전자 (점 크기는 스테이지와 같되 최소 2.5 px)
  - 산란 모형: 전자는 그려진 이온과 직접 충돌하지 않음. 지수분포 자유 시간이 끝나는 무작위 시각에 속도 방향만 다시 뽑음 (위치·이온 배치와 무관). 이온 격자와 진동은 그림 효과
  - Σ: $\tau = \tau_{300}\cdot 300\,\text{K}/T$, $v_d = a\tau$ ($V = 0$이면 $v_d = 0$), $R = \rho L/A$ (기준 도선 10 Ω에서 $L$, $A$, $T$ 비율), 예측 $I = V/R$. 계수 2 s 뒤부터 $\bar I = \Delta Q/\Delta t$, $V/\bar I$ 추가
- 스테이지 아래 $I$-$V$ 그래프: 현재 도선의 예측 직선 + 측정점 (5 s 이상 측정한 전압별로 남음), 전에 측정한 도선의 직선은 회색 → $R \propto L$, $R \propto 1/A$ 비교
- 파라미터 (모두 슬라이더, 변경 시 측정 다시 시작): 전압 0–1.5 V (0.1 V), 온도 200–450 K (10 K) (주), 길이 2–6 cm (0.5 cm), 단면적 1–3 mm² (0.1 mm²) (설정). 회색 직선은 최근 6개 도선까지
- 기본값: 1 V, 300 K, 4 cm, 2 mm² → 10 Ω, 100 mA
- 드리프트 속도는 과장 표시. 실제 값 (드리프트 ≪ 열속도), 전자 1개 = 전하 묶음은 ⓘ 패널에만 기재
- 그림 크기: 이온·전자 점 반지름은 화면 배율에 비례 (데스크톱 75 px/cm 기준, 최소 1.1 px), 전자 점은 도선 윤곽 안에 그림. $\vec v_d$ 화살표 길이 $\propto v_d$ (기본값 0.6 cm, 최대 2.7 cm), 단면 위치 중심

#### Ch 27. Circuits

- **학습 목표**: RC 충·방전의 지수 곡선, 시간상수 $\tau = RC$
- 탭 1 RC 회로
  - 화면: 회로도 (전지 $\mathcal{E}$, 두 갈래 스위치, $R$, $C$). 충전: 전지–$R$–$C$ 고리, 방전: 전지를 뺀 $R$–$C$ 고리
  - 움직이는 점: 관례적 전류 (이동량 $\propto q$ → 전류가 줄면 멈춤), 축전기 판 전하 기호 개수 $\propto q$. 전지 기호 안에서는 점 생략
  - 스위치 드롭다운 (live): 실행 중 전환 → 그 순간의 전하에서 충전 / 방전 시작, 방전 시 $i < 0$. 일시정지 중 전환해도 수치 줄 $i$는 곧바로 새 스위치 위치의 고리 법칙 값 $i = (q_\text{final} - q)/\tau$
  - 그래프: $V_C(t)$, $i(t)$, $q(t)$ (시간 창 $10\tau$, 0.5–20 s 범위로 제한 → $\tau$ = 0.05 s에서도 $5\tau$가 창의 절반). $\tau < 0.5$ s이면 느리게 재생 (배속 $2\tau$/s, $\tau$ = 0.05 s에서 0.1배). 기록은 매 단계 (120개/s). 마지막 전환 시각 기준 $t = \tau$ 표식: 충전 63 %, 방전 37 %, 전류 37 %, 전환 순간 접선 (점선) → $t = \tau$에서 최종값과 만남. 세로 범위는 $\mathcal{E}$, $\mathcal{E}/R$, $C\mathcal{E}$ 기준, 실행 중 $R$·$C$ 변경으로 값이 벗어나면 그 실행의 최댓값까지 넓힘
  - 파라미터: 스위치 (충전 / 방전), $R$ 0.5–4 kΩ 슬라이더 (0.1 kΩ) (주), $C$ 100–1000 μF 슬라이더 (10 μF) (설정). $R$·$C$도 실행 중 변경 가능 (그 순간부터 새 구간, 스위치 전환과 같은 처리. $C$ 변경 시 전하 $q$ 연속 → $V_C = q/C$ 즉시 변화). 수치 줄 $\tau$, $V_C$, $i$
  - 기본값: $R$ = 2 kΩ, $C$ = 1000 μF → $\tau$ = 2 s, 충전
  - 방전으로 시작 (URL 또는 재생 전 선택): 완전히 충전된 축전기 $q = C\mathcal{E}$에서 출발. 재생 전 스위치·$R$·$C$ 변경은 시작 상태를 다시 준비함
  - Σ: $\tau = RC$, 현재 구간의 $q(t)$ (충전 $C\mathcal{E}(1 - e^{-t/\tau})$, 도중 전환 $C\mathcal{E} + (q_0 - C\mathcal{E})e^{-(t - t_s)/\tau}$, 방전 $q_0e^{-(t - t_s)/\tau}$), $V_C = q/C$, 고리 법칙 $i = (\mathcal{E} - V_C)/R$ 또는 $-V_C/R$ (스위치 위치 기준, 수치 줄 $i$와 같음)
- 관찰: $t = 0$ 접선이 $t = \tau$에서 최종값과 만남, 전류는 처음 최대 → 0

#### Ch 28. Magnetic Fields

- **학습 목표**: 로렌츠 힘 $q\vec v \times \vec B$, 원운동, 주기의 속력 무관성
- 탭 1 자기장 속 하전입자
  - 지면으로 들어가는 균일 $\vec B$ (⊗ 격자), 출발점에서 $+x$ 방향 발사, 지나온 궤적
  - $\vec v$ (주홍), $\vec F$ (자주) 표시 (항상 수직) → 일 0, 속력 일정. 정확한 회전 해 (수치 오차 없음)
  - 수치 줄: $r = mv/(\lvert q\rvert B)$, $T = 2\pi m/(\lvert q\rvert B)$
  - 속력 비교 (설정 토글, 기본 켜짐): 1, 2, 3 × 10⁶ m/s 입자 동시 발사 → 반경 다름, 한 바퀴 시간 같음
  - 파라미터: 입자 (양성자, 전자, 알파 입자), $B$ 슬라이더 0.5–2 (0.05 간격, 전자 mT, 이온 T, 실행 중 변경 가능) (주), 속도 비교, $v$ 슬라이더 1–3 × 10⁶ m/s (설정)
  - 궤적은 현재 $B$에서 한 바퀴 남짓 유지 → 낮은 $B$에서도 원이 닫힘. $\vec F$ 화살표는 $F$에 비례하되 궤도 반지름의 70 %가 상한 (높은 $B$에서 중심 관통 방지, 세 입자의 길이 비는 유지), $F$ 라벨은 가장 빠른 입자의 $\vec F$ 화살표 옆 (화살표 중간 양옆·끝 너머 중 다른 입자·화살표에서 가장 먼 자리)
  - 시간: ns 단위, $B$ = 1일 때 한 바퀴 3 s로 재생
  - 화면 크기: 입자별 최대 반경 ($B$ = 0.5) 기준 고정 → 그림의 반지름 $\propto 1/B$ ($B$ 2배 → 원 크기 1/2), $v$ 변화도 그대로 원 크기에 비례
  - 발사기 길이 0.11 × 화면 반폭 (돌아오는 입자와 겹침 축소)
  - Σ: 가장 빠른 입자의 $F = \lvert q\rvert vB$, $r = mv/\lvert q\rvert B$, $T = 2\pi m/\lvert q\rvert B$ 대입 (상수 4자리, 결과는 수치 줄과 같음)
- 탭 2 사이클로트론
  - 두 D 전극 (반지름 $R$ = 5 cm), 틈 6 mm, 양성자는 틈 가운데 선 위에서 정지 출발, $B$ = 1 T. 자석 극은 D 전극보다 12 % 넓음 (⊗ 표시)
  - 출발점은 $y$ 방향으로 옮겨 궤도 중심의 표류를 상쇄 (같은 조건의 시험 계산으로 결정, $y$ 평행이동은 운동을 바꾸지 않음) → 궤도가 D 전극 안에 머묾
  - 틈 전압 $V_0\cos\omega t$, D 전극 극성 (+/−)과 틈 전기장 화살표가 교대 → 나선 궤적
  - 교류 진동수 $f/f_c$ (0.9–1.1, 0.01 간격 슬라이더): 위상이 반 바퀴마다 조금씩 어긋남. 조금 어긋나면 회전 수만 늘고 같은 에너지로 인출, 몇 % 넘게 어긋나면 가속 → 감속, 나선이 다시 감기고 대개 인출 실패. 허용 범위는 회전 수가 적을수록 넓음: 5 kV에서 0.99–1.00, 10 kV에서 0.97–1.02, 20 kV에서 0.94–1.04 (모두 119.7–119.9 keV로 인출)
  - 인출: 궤도 반지름 $mv/\lvert q\rvert B$가 $R$에 이르면 편향판이 꺼냄 → 이후 직선 운동. 출구 에너지 $(qBR)^2/2m$ = 120 keV, 틈 전압과 무관 ($V_0$ = 5, 10, 20 kV 모두 119.7–119.9 keV)
  - 그래프: $V_\text{gap}(t)$, $K(t)$ 계단. 수치 줄 $K$, $r$ (궤도 반지름 $mv/\lvert q\rvert B$, 중심에서의 거리가 아님: 인출 직전 거리 5.00 cm일 때 궤도 반지름 4.82 cm, 인출 시 정확히 $R$). 틈의 $E$ 라벨은 흰 바탕 위 (궤적이 지나가도 읽힘)
  - 파라미터: $f/f_c$, 틈 전압 5–20 kV (1 kV 간격) 슬라이더 (주). 궤적은 Boris 적분으로 미리 계산 (되감기 가능), 시야를 벗어나거나 $\max(12,\ K_\text{max}/2qV_0 + 3)$ 주기에서 자동 정지
  - Σ: $f_c = \lvert q\rvert B/2\pi m$, 교류 $f = (f/f_c)\,f_c$, $K_\text{max} = (qBR)^2/2m$ = 120 keV, 현재 궤도 반지름 $r = v/2\pi f_c$, $K = \tfrac12mv^2$ (수치 줄 $K$, $r$와 같음)

#### Ch 29. Magnetic Fields Due to Currents

- **학습 목표**: 비오-사바르 법칙 (전류 요소 기여의 합), 앙페르 법칙 (닫힌 경로 순환 = 관통 전류)
- 탭 1 비오-사바르 법칙
  - 도선 드롭다운 (주): 직선 도선 (길이 2.2 m, 기본) / 원형 고리 ($R = 0.45$ m), 전류 $I = 10$ A

  - 가우스 (자기): 막대자석 (위아래 면의 속박 전류로 표현)의 닫힌 자기력선, 원을 어디에 두어도 $\Phi_\text{out} = -\Phi_\text{in}$, 순 선속 0
  - 패러데이: 반지름 0.35 m 원 안 균일한 $B$가 증가 ($dB/dt$ 슬라이더 0.2–2 T/s, 기본 1 T/s) → 감아 도는 $\vec E$ 격자 화살표, 원 고리의 $\oint \vec E\cdot d\vec s$ (수치) vs $-d\Phi_B/dt$. $B$의 ⊙ 기호는 고리가 지나는 자리에서 생략, $\vec E$ 화살표는 ⊙ 자리를 비움. 고리 가운데 조절점은 마름모 (⊙와 구별)

  - 좌상단 패널: 적분형 수식 + 측정 수치. 한 줄 의미는 화면 대신 ⓘ 패널 "관찰할 점"에 기재 (화면 최소 표시 원칙)

#### Ch 35. Interference

- **학습 목표**: 이중슬릿 간섭, 경로차와 무늬
- 화면: 왼쪽 평면파 → 이중슬릿 → 2D 파동 전파 애니메이션 → 오른쪽 스크린 (어두운 띠) → 세기 그래프

  - 시간 단위 fs, 재생 시 파면이 슬릿에 닿은 뒤 두 원형파가 퍼져 겹침
- 스크린 기록: $\psi^2$ 시간평균 누적 → 밝기 띠 + 세기 그래프 형성 과정, 모두 덮은 뒤 약 24주기 평균에서 자동 정지

- 순수 두 점원 간섭: 각 슬릿 = 호이겐스 점원 하나 (아주 좁은 슬릿), 회절 포락선 없음
  - 슬릿 폭 설정 제거 (회절 포락선은 Ch 36 주제와 중복). 폭이 있는 이중슬릿은 Ch 36 탭 1 슬릿 2개로 이동
  - 예전 공유 링크의 `a` (슬릿 폭)는 무시됨, 나머지 값은 그대로 적용
- 파라미터 (모두 슬라이더): 슬릿 간격 $d$ 1.5–5 μm, 파장 $\lambda$ 400–700 nm (주, 기본 3 μm, 500 nm), 스크린 거리 $D$ 12–25 μm (설정, 기본 20 μm)

- 탭 1 슬릿 2개 (이중슬릿 = 간섭 × 회절 포락선, 예전 Ch 35 슬릿 폭 설정에서 이동)

  - $a$ = 1.5 μm, $d$ = 4.5 μm ($d/a = 3$): 중앙 포락선 안 밝은 무늬 5개 ($2d/a - 1$), $m = \pm3$ 세기 0.01
  - 스크린이 가까움 ($D \gg ad/\lambda$ 아님) → 두 슬릿의 회절 무늬가 $\pm d/2$만큼 어긋나 사라진 차수가 완전히 0은 아님. $d/a$가 크면 더 뚜렷 ($a$ = 2 μm, $d$ = 6 μm: $m = \pm3$ 세기 0.13, ⓘ 기재)
- 탭 2 위상자 사슬 (정적)
  - 왼쪽: 슬릿 점원 $N$개에서 각도 $\theta$로 나가는 평행 광선, 공통 파면 (파선), 아래 광선의 추가 경로 $\Delta L = a\sin\theta$
  - 가운데: 위상자 화살표 사슬 (색은 탭 1과 같음) + 합 $E_\theta$ (검정), 각도 증가 → 사슬이 말려 원 → 합 0 (극소)
  - 사슬 시작점은 광선·파면과 겹치지 않게 오른쪽으로 이동 (기본 9.2 → 11.6, 최대 약 15). $E_\theta$ 표시는 사슬·광선을 덮지 않는 자리
  - 오른쪽: $I/I_m$ vs $\theta$ 그래프, 점 드래그로 각도 변경
  - 파라미터: 각도 −40–40° (주, 기본 14.5° = 첫 극소 근처), 슬릿 폭 0.5–4 μm (주, 기본 2 μm), 파장 400–700 nm (설정) 모두 슬라이더, 점원 수 8–20 (설정, 정수 조절, 기본 10)
  - 점원 수 하한 8: 범위 안 $\phi/2\pi \le 6.43$ → $N$개 점원 격자의 주극대 ($\phi = 2\pi N$) 없음, 극소 위치 $a\sin\theta = m\lambda$가 $(\sin\alpha/\alpha)^2$과 일치
  - 그래프와 $I/I_m$은 $N$개 점원의 합 (사슬과 일치). 바깥 극대는 연속 슬릿의 $[(\phi/2N)/\sin(\phi/2N)]^2$배: 기본값 1.1–1.2배, $N$ = 8, $a$ = 4 μm, $\lambda$ = 400 nm의 34° 극대 6.8배 (0.023 대 0.0034), 세기는 모두 0.06 미만. 예전 ⓘ의 "조금 높음"을 이 수치로 교체
  - 좁은 화면: 그래프를 슬릿·사슬 아래 배치
  - 수치 줄: 양 끝 위상차 $\phi$, $I/I_m$
  - Σ: $\theta_1 = \sin^{-1}(\lambda/a)$, $\phi = (2\pi/\lambda)a\sin\theta$, $N$개 점원 $I/I_m = [\sin(\phi/2)/N\sin(\phi/2N)]^2$ (수치 줄), 연속 슬릿 $(\sin\alpha/\alpha)^2$ ($N \to \infty$)
- 관찰: $a$ 감소 → 중앙 극대 확산. $a \gg \lambda$ (6 μm) → 슬릿 폭 정도의 밝은 띠 (기하광학 그림자)
- 이중슬릿 = 간섭 × 회절 포락선: 탭 1 슬릿 2개로 구현 (Ch 35는 폭 없는 두 점원 간섭만)

### Part V. 현대물리

#### Ch 37. Relativity

- **학습 목표**: 시간 팽창·길이 수축의 상호성, 두 관측자 시점 동시 비교
- 단위: $c = 1$, 길이 광초 (ls), 시간 s. 색: S 파랑, S′ 주황 (Ch 3 벡터 합의 A·B와 같음)
- 공통 파라미터: 속력 $\beta$ 슬라이더 (주, 0.01 간격). 수치 줄에 $\gamma$
- 탭 1 시간 팽창 (빛 시계)
  - 화면 분할: S (지면) 기준 / S′ (우주선) 기준 (넓은 화면 좌우, 좁은 화면 위아래). 같은 시각 $t$를 각 기준계 시간으로 재생
  - 각 기준계: 자기 시계 (위, 수직 왕복) + 상대 시계 (아래, 지그재그 경로 흔적, 속도 화살표). 시계 위 숫자 = 째깍 수 → 양쪽 모두 상대 시계가 느림
  - 거울 간격 1 ls → $\Delta t_0$ = 2 s, 움직이는 시계 $\Delta t = \gamma\Delta t_0$. $\beta$ 0–0.99 (기본 0.8)
  - 수치 줄: $\gamma$, $\Delta t_0$, $\Delta t$
  - Σ: $\gamma$ 대입, $\Delta t_0 = 2L/c$, $\Delta t = \gamma\,\Delta t_0$, 째깍 수 $n_0 = \lfloor t/\Delta t_0\rfloor$·$n = \lfloor t/\Delta t\rfloor$ (재생 중 갱신)
- 탭 2 길이 수축
  - 같은 분할 화면: 자기 막대 (고유 길이 4 ls, 1 ls 눈금) + 상대 막대 ($L_0/\gamma$, 눈금도 수축) 이동. $\beta$ 0–0.99 (기본 0.8)
  - 수치 줄: $\gamma$, $L_0$, $L$
  - Σ: $\gamma$ 대입, $L = L_0/\gamma$
- 탭 3 시공간 도표 (세계선에서 효과 읽기)
  - S 직교축 ($x$, $ct$, 파랑) + S′ 기울어진 축 ($x'$, $ct'$, 주황), 두 격자 (설정 토글), 원점의 빛 원뿔 파선
  - 읽기 (주): 시간 팽창 (기본) / 길이 수축 / 사건 순서. $\beta$ 0–0.8 (주, 기본 0.6 → $\gamma$ = 1.25)
  - 시간 팽창: $ct$축 눈금 (S 시계, $x = 0$) + $ct'$축 눈금 (S′ 시계, $x' = 0$, $ct'$ 1 s 간격). 사건 E = S′ 시계의 $ct'$ = 2 s (탭 1 빛 시계 한 번 째깍) → E에서 $ct$축까지 S 동시선, 만나는 점 $ct = \gamma \times 2$ s (기본 2.50 s)
  - 길이 수축: S′에 정지한 막대 ($x'$ = −3.5 ~ −0.5 ls, $L_0$ = 3 ls)의 세계 띠. 앞 끝 사건 F ($ct'$ = 2.5 s)를 지나는 S 동시선 → $L = L_0/\gamma$ (파랑 F–R, 기본 2.40 ls), S′ 동시선 → $L_0$ (주황 F–R′)
  - 사건 순서: A는 원점 고정, B 드래그 (0.1 간격, 기본 (3, 1)). B를 지나는 두 동시선, $x$축과 $x'$축 사이 쐐기 회색 음영 → 쐐기 안의 B는 S와 S′에서 A와의 순서 반대 (기본 $\Delta t$ = 1 s, $\Delta t'$ = −1 s), 쐐기는 항상 빛 원뿔 밖
  - 좌상단 패널: 읽기별 사건의 $(x, ct)$, $(x', ct')$ 좌표 + 읽은 값 ($\Delta t = \gamma\,\Delta t_0$, $L = L_0/\gamma$, 또는 $\Delta t$·$\Delta t'$). 수치 줄: $\gamma$
  - 선분 이름 $L$·$L_0$: 축·빛 원뿔·막대 세계선과 겹치지 않는 위치 자동 선택
  - Σ: $\gamma$ + 읽기별 로런츠 변환, 좌상단 표와 같은 소수 둘째 자리
    - 시간 팽창: $x_\text{E}$, $ct_\text{E}$, $\Delta t = \gamma\,\Delta t_0$
    - 길이 수축: $L = x_\text{F} - x_\text{R}$, $L_0 = x'_\text{F} - x'_\text{R'}$, $L = L_0/\gamma$
    - 사건 순서: $x'_\text{B}$, $\Delta t' = \gamma(\Delta t - v\Delta x/c^2)$, 불변량 $(c\Delta t)^2 - \Delta x^2$
  - 탭 4와 역할 구분: 동시성의 상대성 자체는 탭 4, 탭 3은 도표에서 시간 팽창·길이 수축·인과 순서를 읽는 법. 옛 공유 링크의 사건 A 좌표는 무시
  - ⓘ 용어 정의 (교재에 민코프스키 도표 없음): 사건, 세계선, 세계 띠, 동시선, 빛 원뿔 (안쪽 시간꼴, 바깥 공간꼴)
- 탭 4 동시성의 상대성 (기차 섬광)
  - 위: S (지면) 기준, 아래: S′ (기차) 기준. 고유 길이 4 ls 기차 가운데에서 $t = t' = 0$에 섬광, 빛이 양 끝에 도달하면 원 표시와 도착 시각
  - 기차 기준: 양 끝 동시 도착 ($t'$ = 2 s), 지면 기준: 뒤쪽 먼저, $\Delta t = \gamma\beta L_0$
  - 지면 기둥: 지면 기준 1 ls 간격, 기차 기준 $1/\gamma$ ls 간격 (길이 수축)으로 왼쪽 이동
  - $\beta$ 0.1–0.8 (기본 0.6, $\Delta t$ = 3 s), 앞쪽 도착 뒤 자동 정지. 수치 줄: $\gamma$, $\Delta t$, $\Delta t'$
  - Σ: $\gamma$, $L/2 = L_0/2\gamma$, $t_\text{R} = (L/2)/(c + v)$, $t_\text{F} = (L/2)/(c - v)$, $\Delta t = t_\text{F} - t_\text{R}$, $t'_\text{R} = t'_\text{F} = L_0/2c$ ($\Delta t'$ = 0)

#### Ch 38. Photons and Matter Waves

- **학습 목표**: 파속이 입자처럼 행동, 드브로이 파장
- 탭 1 파속 (자유 전자, 단위 nm·fs)
  - 위: $\mathrm{Re}\,\psi$와 $\lvert\psi\rvert^2$ (음영), 가운데: 군속도로 움직이는 고전 입자 점과 $x$축, 아래: 성분 진폭 막대 (파수 $k$축, $k$ 라벨은 그래프 제목 줄 오른쪽 → $M = 33$에서도 막대와 겹침 없음)
  - 평면파 수 $M$ (주, 스테퍼): 1–33, 기본 9. 간격 일정 ($\delta k = 2\pi/42\ \text{nm}^{-1}$), 가우스 진폭
  - 표시 (주): Re ψ와 |ψ|² / Re ψ / |ψ|². 중심 파수 $k_0$ 슬라이더 5–15 nm⁻¹ (설정, 기본 10 → 3.8 eV)
  - 분산 $\omega = \hbar k^2/2m$ 포함 → 파속은 군속도 $v_\text{g} = \hbar k_0/m = p/m$로 이동하며 퍼짐, 마루는 절반 속도 (위상속도)
  - 수치 줄: $\Delta x$, $\Delta k$, $\Delta x\,\Delta k$ (가우스 극한 ≈ 0.5)
  - Σ: $v_\text{g} = \hbar k_0/m$, $v_\text{p} = v_\text{g}/2$, 고전 입자 위치 $x = v_\text{g}t$ (재생 중 갱신), $\Delta x$·$\Delta k$, $\Delta x\,\Delta k$와 1/2 비교. 파속 아님 ($M \le 3$) → $\Delta x > 42/6$ = 7 nm 조건만 표시
  - $\Delta x$는 반복 길이 42 nm 한 주기 안의 표준편차 → $\Delta x$ < 7 nm (주기의 1/6, 이 폭의 가우스는 주기 경계에서 최댓값의 1 %)일 때만 표시, 아니면 – ($M$ = 1–3). 예전 $M$ = 3에서 $\Delta x\,\Delta k$ = 0.417 (< 1/2)로 표시됨: 주기 전체에 퍼진 $\lvert\psi\rvert^2$의 표준편차 (상한 $L/\sqrt{12}$ = 12.1 nm)라 불확정성 관계와 무관. $M \ge 4$는 $t = 0$에서 0.50–0.51, 파속이 퍼지며 증가 (최대 3.2, $M$ = 33, $k_0$ = 5 nm⁻¹, 끝 시점)
  - ⓘ: $\Delta x$, $\Delta k$ = 표준편차, $\Delta p = \hbar\,\Delta k$, $\Delta x\,\Delta p \ge \hbar/2$ (교재의 $\ge \hbar$는 크기 정도 표현)
  - 고전 입자가 오른쪽 끝에 닿으면 자동 정지
- 탭 2 물질파 회절 (장면 id `debroglie` 유지 → 옛 링크도 탭 2로 열림, 옛 `eK` 값은 무시)
  - 입자를 하나씩 주기 구조에 통과시켜 화면에 점으로 기록 → 점이 쌓여 $\lvert\psi\rvert^2$ 무늬 형성 (점 하나 = 입자 하나)
  - 화면: 위 로그 자 ($10^{-36}$–1 m, $\lambda$ 아래 표식, $d$·입자 크기 위 표식), 아래 왼쪽부터 입자원 → 구조 ($d$ 값 라벨) → 화면 (도달 점) → 도달 수 막대 + 기대값 $N P$ 점선 계단 ($\lvert\psi\rvert^2$) → 화면 좌표 $y$ 축
  - 입자 (주): 전자 / 중성자 / $\text{C}_{60}$ 분자 / 야구공 (0.145 kg)
  - 속력 $v$ (주, 로그 슬라이더, 입자별 범위): 전자 $5\times10^5$–$1.5\times10^8$ m/s (0.71 eV–79 keV, 기본 $4.36\times10^6$ m/s = 54.0 eV), 중성자 100–30000 m/s (기본 2200), $\text{C}_{60}$ 50–500 m/s (기본 220), 야구공 1–50 m/s (기본 40)
  - 두 번째 컨트롤을 속력으로 통일: 네 입자 모두 같은 물리량·단위. 운동에너지는 Σ 패널 (전자 eV·keV, 중성자 meV, 야구공 J)
  - 구조 (설정): 자동 (전자·중성자 → 결정, $\text{C}_{60}$ → 격자, 야구공 → 이중 슬릿, 기본) / 결정 / 회절격자 / 이중 슬릿
    - 결정: 니켈 표면 원자열 $d$ = 0.215 nm, 원자 20개 (크기 0.05 nm 가우스 포락선), 화면 5 cm 뒤, $\pm$10 cm
    - 회절격자: $d$ = 100 nm, 슬릿 폭 50 nm, 20개, 화면 1.25 m 뒤, $\pm$150 μm (Arndt 등 1999)
    - 이중 슬릿: $d$ = 1 mm, 폭 0.25 mm, 화면 1 m 뒤, $\pm$1 mm. 화면과 같은 축척으로 그림 → 슬릿과 그림자 띠 정렬
  - 분포: 프라운호퍼 세기 ($N$주기 간섭 × 슬릿 포락선 × $\cos^2\theta$)를 슬릿 위치·폭만큼 옮겨 더함 → 큰 무늬는 프라운호퍼, 아주 작은 무늬는 기하학적 그림자로 수렴
  - 표본추출: 차수 선택 + 차수 안 역CDF + 기각 (정확한 표본), 기대값은 $u = d\sin\theta/\lambda$ 구적 + 구멍 합성곱. 테스트: 6개 경우 $\chi^2$ 일치
  - 도달: 처음 초당 4개 (하나씩 날아가는 점) → 점점 빨라짐, 3000개 (약 19 s)에서 자동 정지. 날아가는 시간 = 직전 도달 간격의 2배 (최대 0.6 s) → 동시에 1–2개만 비행
  - 무늬 간격 표식 $\Delta y$ (0 → 1차 극대 $L\tan\theta_1$): 1차 극대 존재, 화면 분해능 $\delta$ (화면 높이의 1/30) 이상, 화면 안일 때만 표시
  - 표식 생략 시 Σ 패널 문구: $\Delta y \ll \delta$ (무늬 분해 불가) / $\Delta y > Y$ (1차 무늬 화면 밖) / $\lambda/d > 1$ (1차 무늬 없음)
  - Σ 패널: $m$, $v$, ($\gamma$), $p$, $K$, $\lambda = h/p$, $\sin\theta_1 = \lambda/d$ (큰 각은 $\theta_1$ 함께), $\Delta y \approx \lambda L/d$ 또는 $L\tan\theta_1$
  - 수치 줄: $\lambda$, $\Delta y$ (1차 없으면 –), $N$
  - 대표값: 54 eV 전자 + 니켈 → 0.167 nm, 50.9° (데이비슨-거머 측정 50°). 열중성자 → 0.180 nm, 56.8°. $\text{C}_{60}$ 220 m/s → 2.52 pm, $\Delta y$ = 31.5 μm. 야구공 40 m/s → $1.14\times10^{-34}$ m, $\Delta y = 1.1\times10^{-31}$ m → 그림자 두 줄
  - 결정의 전자: 32.5 eV 이하 1차 없음, 약 1.9 keV 이상 $\Delta y < \delta$ → 중앙 덩어리
- 입자 하나씩 누적은 탭 2에서 구현 (2D 파동 엔진 대신 해석적 분포)

  - 기본값: 무한 우물 1 nm → $E_1$ = 0.376 eV, $E_n \propto n^2$
  - 이중 우물: 짝 상태 중 위 상태를 파선으로 그려 대칭·반대칭 구분
  - Σ: 값은 도표의 솔버 준위와 같음
    - 무한 우물: $E_1 = h^2/8mL^2$ 대입, $E_n = n^2E_1$ ($n$ ≤ 3)
    - 유한 우물: $E_1 < h^2/8mL^2$, 벽 침투 길이 $\delta = \hbar/\sqrt{2m(U_0 - E_1)}$. 속박 상태 수 $N = \lceil 2z_0/\pi\rceil$, $z_0 = (L/2)\sqrt{2mU_0}/\hbar$ (그림의 준위 수와 항상 같음)
    - 조화: $E_0 = \hbar\omega/2$, $E_1 = 3\hbar\omega/2$, $E_1 - E_0 = \hbar\omega$
    - 이중 우물: 쌍 분리 $E_2 - E_1$, $E_4 - E_3$
- 탭 2 중첩 상태 (부가 항목 구현)
  - 두 정상상태를 같은 비율로 겹친 $\lvert\Psi(x,t)\rvert^2$ 시간전개, 평균 위치 $\langle x\rangle$ 점 + $\langle x\rangle(t)$ 그래프 (시간 단위 fs)
  - 중첩 (주): 1 + 2 / 1 + 3 / 2 + 3, 조화 퍼텐셜은 양자수에 맞춰 0 + 1 / 0 + 2 / 1 + 2 (준위 이름 $E_0$, $E_1$과 일치). 퍼텐셜 (주)
  - 설정은 탭 1과 같되 우물 폭 1.0–1.5 nm, 유한 우물 깊이 1.8–4.5 eV로 제한 → 모든 퍼텐셜에 속박 상태 3개 이상, 선택한 쌍이 항상 존재 (다른 쌍으로 대체 없음)
  - 수치 줄: $\Delta E = E_b - E_a$, 주기 $T = h/(E_b - E_a)$, $\langle x\rangle$. $\Delta E$ 추가 이유: 높고 넓은 장벽 (1.5 nm, 4.5 eV, 0.5 nm)에서 $E_1$, $E_2$가 모두 0.148 eV로 표시됨
  - 주기 범위 1.37 fs (무한 우물 1 + 3) – 12 870 fs (위 장벽), 기본 3.67 fs (무한 우물), 61.4 fs (이중 우물), 20.7 fs (조화)
  - 그래프 창 = 3주기, 재생 속도 = 1배속에서 한 주기 2초 (예전 고정 40 fs 창·2 fs/s → 긴 주기에서 $\langle x\rangle$가 평평). 한 걸음 = $\max(0.005\ \text{fs}, T/280)$ → 주기마다 기록 70개, 기록 한도 (10 000개) 안에서 창 전체 유지
  - ⓘ: 정상상태, $\psi$ (공간 부분)와 $\Psi(x,t)$ (전체), $\langle x\rangle$ (위치의 기댓값) 정의
  - Σ: $\Delta E = E_b - E_a$, $T = h/\Delta E$, $t/T$, $\langle x\rangle = \bar x + A\cos(2\pi t/T)$ (재생 중 갱신). 같은 홀짝 쌍 → $A$ = 0, $\langle x\rangle = \bar x$
- 관찰
  - 무한 우물: $E_n \propto n^2$, 폭 감소 → 준위 간격 증가
  - 유한 우물: 벽 바깥 지수 감쇠 침투 (고전 금지 영역), 속박 상태 수 유한 (1 nm 우물, 깊이 1·2·4 eV → 2·3·4개)
  - 유한 우물 준위는 정확해: 짝 $z\tan z = \sqrt{z_0^2 - z^2}$, 홀 $-z\cot z = \sqrt{z_0^2 - z^2}$ ($z = kL/2$)을 이분법으로 풀고 $\psi$는 안쪽 $\cos/\sin$, 바깥 $e^{-\kappa(\lvert x\rvert - L/2)}$. 이전 유한차분 (양쪽 2.5 nm 상자, 벽에서 $\psi = 0$)은 감쇠 길이가 상자보다 긴 얕은 상태를 $U_0$ 위로 밀어 슬라이더 조합 861개 중 37개에서 마지막 준위를 놓침 (예: 1 nm, 3.4 eV의 4번째 준위, 결합 0.4 meV) → 0개 (사용자 요청, 2026-11-18). 깊은 준위는 두 방법 차이 1.6 meV 이하
  - 조화: 등간격 $\hbar\omega$, 바닥상태 $\hbar\omega/2$ (Ch 15 연계)
  - 이중 우물: 준위 쌍 분리 (결합·반결합) → Ch 41 띠 형성의 출발점, 1 + 2 중첩은 터널링 진동

#### Ch 40. All About Atoms

- **학습 목표**: 스핀 양자화, 측정 축 의존성
- 원자는 오븐에서 차례로 나옴 (실행마다 새 난수 시드 → 매번 다른 결과). 스핀 상태는 zx 평면의 방향 $\alpha$, 축 $\theta$ 측정의 + 확률 $\cos^2((\theta - \alpha)/2)$
- 탭 1 슈테른-게를라흐 실험
  - 왼쪽: 옆에서 본 장치 (오븐, 슬릿, N·S 자극, 스크린)와 날아가는 원자, 오른쪽: 정면에서 본 스크린의 도달 점 (위 파랑, 아래 주홍)과 개수
  - 모형 (주): 고전 예측 (자기 모멘트 방향 무작위 → $\mu_z$ 균일 → 연속 띠) / 실제 (양자, 기본 → 두 줄). 원자 수 (주): 200·1000·5000
  - 수치 줄: 도달 원자 수 $N$, 위쪽 비율 $N_\uparrow/N$
  - Σ: 모형별 예측 (양자 $S_z = \pm\hbar/2$, 고전 $\mu_z \in [-\mu, \mu]$) → 위쪽 확률 1/2, 측정 $N_\uparrow/N$, 예상 요동 $\sigma_P = \sqrt{P(1-P)/N}$
- 탭 2 연속 측정 (z → x → z)
  - 장치 상자 (SG-$z$, SG-$x$, SG-$z$)와 측정 축 아이콘, 막힌 출구 (검은 막대 + 멈춘 원자 수), 마지막 장치의 두 검출기 개수, 측정 비율 막대와 이론값 눈금 (검출기 사이 공간이 부족한 좁은 화면에서는 막대 생략)
  - x 장치 통과 (주): +x만 (기본) / −x만. 원자 수 (주): 100·400 (기본)·1000
  - −z를 막았는데도 마지막에 −z 반 재등장 → x 측정이 z 정보 소거. 마지막 장치 도달 원자 = 전체의 1/4
  - z → z, z → x 배열은 탭 3의 $\theta$ = 0°, 90°와 같아 제외. 옛 공유 링크의 배열 값은 무시
  - 수치 줄: 측정 비율 $N_+/(N_+ + N_-)$, 이론값 $P_+$
  - Σ: 경로 확률 $P(+z \to \pm x \to +z)$ = 0.5 × 0.5 × 0.5, $P_+$, 측정 비율, $\sigma_P$
- 탭 3 측정 확률
  - SG-$z$ (+만 통과) → SG-$\theta$. 두 번째 축 각도 슬라이더 0–180° (주, 기본 60°), 원자 수 100–4000 (주)
  - 스테이지 아래: $\cos^2(\theta/2)$ 곡선, 이론값 (빈 원)과 측정값 (점 + 오차 막대 $\sqrt{P(1-P)/N}$). 좁은 화면에서는 곡선 그래프가 전체 폭 사용, 눈금 수는 폭에 맞춤, 축 이름 $P_+$·$\theta$는 그래프 밖
  - 그래프: 누적 비율 $N_+/(N_+ + N_-)$의 시간 변화 + 이론값 파선 → 원자 수가 늘수록 수렴
  - 수치 줄: 측정 비율, $\cos^2(\theta/2)$
  - Σ: $P(+\theta \mid +z) = \cos^2(\theta/2)$ 대입, 측정 비율, $\sigma_P$

#### Ch 41. Conduction of Electricity in Solids

- **학습 목표**: 밴드갭에 따른 금속/반도체/절연체 구분, 금속의 전도 원리, 반도체의 특성
- 탭 1 띠 형성 (Ch 39 솔버)
  - 왼쪽: 폭 0.5 nm·깊이 5 eV 사각 우물 $N$개의 $U(x)$와 준위. 오른쪽: $N$ = 1, 2, 3, 4, 6, 8, 12, ∞별 준위 막대, 현재 $N$ 강조, ∞ 열은 크로니히-페니 띠 + $E_\text{g}$ 괄호
  - 두 그림 배경에 무한 사슬의 허용 띠 음영
  - 우물 수 스테퍼 1–12 (주, 기본 8), 우물 간격 슬라이더 0.1–0.5 nm (주, 기본 0.1 nm). 오른쪽 그림에 현재 $N$ 열이 없으면 추가. 수치 줄: $E_\text{g}$, 첫 띠 폭 $W_1$
  - ⓘ 크로니히-페니 식 기호 정의: $a$ 우물 폭, $b$ 장벽 폭, $d = a + b$ 주기, $k$ 우물 안 파수, $\kappa$ 장벽 안 감쇠 상수, $q$ 블로흐 파수
  - Σ: $N$개 준위 퍼짐 $E_{1,N} - E_{1,1}$, 첫 띠 폭 $W_1 = E_{1,\max} - E_{1,\min}$, $E_\text{g} = E_{2,\min} - E_{1,\max}$ (크로니히-페니)
- 탭 2 띠 채움과 분류
  - 왼쪽: 띠 상자 + 전자 (파랑 점)·정공 (주홍 고리), 띠틈 괄호 $E_\text{g}$. 오른쪽: 같은 에너지축의 페르미-디랙 $f(E)$, 전도띠 바닥 점유 확률 점. 두 그림을 가로지르는 $E_\text{F}$ 파선
  - 물질 (주): 금속 (Na, 부분적으로 찬 띠) / Ge (0.66 eV) / Si (1.12 eV, 기본) / 다이아몬드 (5.5 eV). 온도 슬라이더 0–600 K (주, 기본 300 K)
  - $f(E)$ 축 (설정): 로그 (기본, $10^{-30}$–1) / 선형
  - 전도띠 전자·정공 점 개수: $n_i = \sqrt{N_c N_v}\,e^{-E_\text{g}/2kT}$의 로그에 비례 (과장, ⓘ에 기재). 수치 줄: $E_\text{g}$ (금속은 –, $E_\text{F}$가 띠 안), $n$
  - Σ: $kT$, $E_\text{g}/2kT$, $n_i = \sqrt{N_cN_v}\,e^{-E_\text{g}/2kT}$, $E_\text{F} = \tfrac12 kT\ln(N_v/N_c)$, $f(E_c)$ (그래프의 점). 금속: $n$, $f(E_\text{F} + kT)$ = 0.269. $T$ = 0 → $n_i$ = 0
- 탭 3 전기 전도
  - 1차원 띠 $E(k) = -2\gamma\cos ka$ ($\gamma$ = 1 eV 호핑 에너지, 시간 $t$와 구분) 위 $k$ 상태 32개: 찬 상태 파랑 점, 빈 상태 회색 고리. 전기장 화살표
  - 전기장 $\mathcal{E}$ (에너지 $E$와 구분) → 찬 상태 전체가 $k$ 방향으로 이동, 산란 ($\tau$ = 10 fs)으로 $\Delta k = -e\mathcal{E}\tau/\hbar$에서 정지
  - ⓘ 기호 정의: $E$, $\mathcal{E}$, $k$, $a$ (격자 상수, 탭 1의 우물 폭과 다른 양), $\gamma$, $\Delta k$ (분포 전체의 이동량), 띠 경계 $\pm\pi/a$
  - 띠 채움 (주): 절반 (금속, 기본) / 거의 참 (빈 상태 2개) / 꽉 참 (절연체). 전기장 슬라이더 0–1 (임의 단위, 주, 기본 1, 재생 중 변경 가능)
  - 그래프 $J(t)$ (임의 단위): 절반 → 지수적으로 일정값, 꽉 참 → 항상 0 (띠 경계를 넘은 전자가 반대편에서 돌아옴). 수치 줄: $\Delta k$, $J$
  - Σ: $\Delta k_\infty = -e\mathcal{E}\tau/\hbar$, 현재 $d\Delta k/dt = -e\mathcal{E}/\hbar - \Delta k/\tau$ (재생 중 갱신, 정상상태 0), $J = -\tfrac{1}{32}\sum_k f_k\sin(k + \Delta k)a$
- 탭 4 도핑 (실리콘)
  - 왼쪽: 띠 상자, 주개 준위 ($E_c$ − 0.045 eV, 이온화 ⊕ / 중성은 전자 점) 또는 받개 준위 ($E_v$ + 0.045 eV, 이온화 ⊖), 전도띠 전자·원자가띠 정공 점 (8개 = 불순물 농도 비율), $E_\text{F}$ 파선
  - 오른쪽: $n$, $p$, $n_i$의 온도 의존 (로그축, 30–800 K), 현재 온도 세로선과 점 → 동결·불순물·진성 영역
  - 도핑 (주): 도핑 없음 (순수 Si) / n형 (P, 기본) / p형 (B). 온도 슬라이더 50–800 K (주). 도핑 세기 = 불순물 농도 로그 슬라이더 $10^{13}$–$10^{18}\ \text{cm}^{-3}$ (주, 도핑 없음이면 숨김, 유효숫자 2자리, 기본 $10^{16}$)
  - 도핑 없음 다시 추가 (사용자 요청, 2026-11-18. 이전에는 탭 2와 겹쳐 제거): $n = p = n_i$, $E_\text{F}$ = 띠틈 가운데 $+ \tfrac12 kT\ln(N_v/N_c)$, 불순물 준위 없음. 점 8개 = $10^{16}\ \text{cm}^{-3}$ → 300 K ($n_i = 6.7\times10^{9}$) 점 없음, 800 K ($2.2\times10^{16}$) 점 다수. 옛 공유 링크 `type=i`도 다시 유효
  - 농도 범위: $10^{13}$ (300 K $E_c - E_\text{F}$ = 0.38 eV, 450 K부터 진성) – $10^{18}$ (주개 76 % 이온화, $E_c - E_\text{F}$ = 0.093 eV ≈ 3.6 $kT$ → 볼츠만 근사 한계 안)
  - 페르미 준위: 전하 중성 $n + N_A^- = p + N_D^+$ (볼츠만 근사) 이분법 풀이. 수치 줄: $n$, $p$
  - Σ: carriers() 결과 대입
    - 도핑 없음: $n = p = n_i$
    - n형: $n = p + N_D^+$, $p = n_i^2/n$. p형: $p = n + N_A^-$, $n = n_i^2/p$
    - 페르미 준위: 다수 운반자 밀도에서 $E_c - E_\text{F} = kT\ln(N_c/n)$, $E_\text{F} - E_v$ (p형 $E_\text{F} - E_v = kT\ln(N_v/p)$)

#### Ch 42. Nuclear Physics

- **학습 목표**: 확률적 붕괴 → 지수 법칙, 반감기
- 화면: 핵 격자 ($N_0$개), 각 핵이 독립적으로 붕괴 (어미핵 파랑 → 딸핵 회색, 방금 붕괴한 핵은 잠시 주황), 위쪽에 어미핵·딸핵 범례
  - 붕괴 시각은 핵마다 지수분포에서 추출 (매 순간 붕괴 확률 $\lambda\,dt$와 동등, 실행마다 새 난수 시드)
- 그래프: $N(t)$ 계단 곡선 + $N_0 e^{-\lambda t}$ 파선, 반감기 표식 ($N_0/2$, $N_0/4$, $N_0/8$ ↔ $T_{1/2}$, $2T_{1/2}$, $3T_{1/2}$). $kT_{1/2}$ 이름은 그래프 맨 위 한 줄, 세로 안내선이 이름까지 이어짐 → 곡선·계단과 겹침 없음
- $N_0$ 드롭다운: 10, 100, 1000 (기본), 10000 → 작은 수에서 요동, 큰 수에서 지수 곡선
- 대조: 개별 핵의 붕괴 시점 예측 불가 / 집단의 반감기 일정
- 동위원소 프리셋: $^{14}\text{C}$ (5730 y, 기본), $^{131}\text{I}$ (8.02 d), $^{238}\text{U}$ ($4.47\times10^9$ y) → 시간축 단위 자동 변경 (×10³ y, d, ×10⁹ y), $5T_{1/2}$ 후 자동 정지
- 수치 줄: $N$, $N/N_0$, $t/T_{1/2}$
- Σ: $\lambda = \ln 2/T_{1/2}$ (y⁻¹ 또는 d⁻¹), $t/T_{1/2}$, 기대값 $N_0(1/2)^{t/T_{1/2}}$, 측정 $N/N_0$ (재생 중 갱신)
- 미구현: 연대 측정 (남은 비율 → 경과 시간)

### 6.1 광전 효과 (→ Ch 38)

- **학습 목표**: 문턱 진동수와 세기 무관한 $K_\text{max}$ → 광자 $hf$, $I$–$V$ 곡선의 차단점 $-V_\text{stop}$이 진동수에 따라 $h/e$ 비율로 이동
- 경로 `#/ch/101`, 탭 1개, 코드 `src/sims/review/photoelectric/`
- 스테이지 (넓은 화면: 왼쪽 광전관, 오른쪽 $I$–$V$ 그래프 / 좁은 화면: 위아래 반반)
  - $V_\text{stop}$–$f$ 측정 그래프·측정/지우기 버튼·측정 점 제거 (사용자 요청, 2026-11-18: 측정 버튼이 걸어 준 전압과 무관하게 공식값만 찍어 측정 의미 없음). 옛 링크의 `D`는 무시
  - 광전관: 유리관, 방출판 (금속 기호), 수집판, 위에서 들어오는 빛줄기와 광자 (색은 $\lambda = c/f$의 `wavelengthRGB`, 380 nm 미만 회색). 빛줄기 오른쪽 위에 유도량 "$\lambda$ = … nm" (380 nm 미만이면 "UV" 덧붙임)
  - 광자가 방출판에 닿으면 흡수 표식, $hf > \Phi$이면 전자 1개 방출. 전자 속력 $\propto \sqrt{K}$, 간극 안 등가속도 ($\tfrac12 mv^2 = K + eVx/d$) → 역전압에서 되돌아감
  - 회로: 전원 기호 ($V \ge 0$이면 긴 판이 수집판 쪽) + "$V$ = …" , 전류계 (A) + 전류값 (nA, 모형 식)
  - 에너지 막대 (관 왼쪽): 높이 $hf$, 점선 $\Phi$, $\Phi$ 위 부분은 $K$ 색 (`#56B4E9`). $hf < \Phi$이면 막대가 점선 아래 → 문구 없는 문턱 표시
  - $I$–$V$ 그래프: $V$ −5–3 V, 현재 $V$에 점, 차단 위치에 "$-V_\text{stop}$". 세로축 위끝은 광출력별 고정 (가장 긴 방출 파장의 포화 전류 위 깔끔한 값)
- 조작
  - 진동수 $f$ (주, 슬라이더): 4.0–16.6 ×$10^{14}$ Hz (약 750–181 nm), 0.1 간격, 기본 7.5 ($\lambda$ ≈ 400 nm). 2차 검토에서 파장 조절을 진동수 조절로 바꿈 (사용자 요청), 파장은 유도량
  - 전압 $V$ (주, 슬라이더): −5–3 V, 0.05 V 간격, 기본 0
  - 설정: 금속 (드롭다운) Cs 2.14 / Na 2.28 (기본) / Zn 4.33 / Cu 4.65 / Pt 5.65 eV, 광출력 $P$ (슬라이더) 0.1–2.0 µW (기본 1.0), 고전 예측 (토글, 기본 끔)
- 모형
  - $hf$ ($f$ 직접 입력), $\lambda = c/f$, $K_\text{max} = hf - \Phi$, $V_\text{stop} = K_\text{max}/e$. 문턱 진동수 $f_0 = \Phi/h$: Cs 5.17, Na 5.51, Zn 10.47, Cu 11.24, Pt 13.66 ×$10^{14}$ Hz ($\lambda_0$ = 579·544·286·267·219 nm)
  - 양자 효율 1 → $I_\text{sat} = eP/(hf)$ (Na, 7.5 ×$10^{14}$ Hz, 1 µW: 322 nA)
  - $K$ 균일 분포 $[0, K_\text{max}]$, 수집판 방향 1차원 → $-V_\text{stop} < V < 0$에서 $I = I_\text{sat}(1 - e\lvert V\rvert/K_\text{max})$, $V \ge 0$ 포화, $V \le -V_\text{stop}$이면 0
  - 고전 예측 (회색 파선): $I$–$V$ 그래프에 차단 $-V_\text{cl}$ ($V_\text{cl}$ = 2 V/µW × $P$, 임의 척도), 문턱 없음. 지연 $t_\text{cl} = \Phi/(SA)$ ($S = P$/1 cm², $A = \pi(0.1\ \text{nm})^2$; Na, 1 µW → 1.2×10³ s)
- 현재 값 대입 (Σ): $hf = (4.136\times10^{-15}\ \text{eV s})\,f$ 대입, $\lambda = c/f$와 $f_0 = \Phi/h$, $eV_\text{stop} = K_\text{max} = hf - \Phi$ (문턱 아래면 0, $f < f_0$), 고전 예측을 켜면 $t_\text{cl}$
- 수치 줄: $hf$, $V_\text{stop}$, $I$
- 표시 축척 (ⓘ에만 기재): 화면 광자 수 $\propto P/(hf)$, 전자 속력 $\propto \sqrt{K}$. 재생 전 화면은 2.5 s 미리 진행한 정상 상태, 시계 숨김
- 테스트 (`tests/review-photoelectric.test.ts`): 진동수 슬라이더 범위·간격·기본값, 모든 금속 $K_\text{max} = hf - \Phi$, $f_0 = \Phi/h$ (Na 5.51, Cs 5.17)와 0.1 격자에서 문턱 아래 한 칸 전류 0·위 한 칸 전류, 16.6 ×$10^{14}$ Hz에서 $V_\text{stop} \le$ 5 V, 문턱 아래·$V \le -V_\text{stop}$에서 전류 0, 포화·선형 감소, 측정 그래프·버튼·`D` 없음 (옛 링크 열림), 대입 패널 문자열, i18n 키

### 6.2 수소 원자 (→ Ch 39)

- **학습 목표**: 수소 에너지 준위 $E_n = -13.6\ \text{eV}/n^2$, 전이 하나 → 광자 하나 → 선스펙트럼, 계열과 계열 한계
- 경로 `#/ch/102`, 코드 `src/sims/review/hydrogen/` (`physics.ts`, `spectrum.ts`, `stage.ts`, `scene.ts`)
- 물리: 수소 뤼드베리 상수 $R_\text{H} = R_\infty/(1 + m_e/m_p)$ (환산 질량), $E_1 = -13.598$ eV. 파장은 진공 값, 공기 중 파장은 Edlén 식 (테스트 전용)
- 탭 1 전이와 선스펙트럼 (정적 장면)
  - 왼쪽: $E$에 선형인 준위 도표 ($-14.6$ ~ 0.7 eV), $n = 1$–4 라벨, 0 eV 위 비속박 영역 회색. 파선 상자 = $-0.62$ ~ 0.06 eV 구간
  - 가운데: 파선 상자 확대 그림 ($n \ge 5$). 라벨은 $n = 5$부터 14 px 간격이 유지되는 데까지 연속, 선택한 준위는 항상 라벨 → 라벨 겹침 없음 (테스트로 보장)
  - 전이 화살표 (검정) 두 그림 모두, 양 끝에 끌기 손잡이 (파란 원 + 흰 ▲▼, 반지름 9.5 px, 끄는 동안 테두리 확대). 화살표는 손잡이 가장자리 사이에 그려 화살촉이 가려지지 않음, 두 준위가 너무 가까우면 (예: 4 → 3) 손잡이를 화살표 왼쪽으로 비켜 놓음
  - 광자 (물결선)는 화살표가 긴 그림에서 준위 사이 가장 넓은 빈칸에. 방출: 바깥으로, 흡수: 안으로
  - 광자 색 = `wavelengthRGB`, 380–750 nm 밖은 회색 + 짧은 영역 표시 (자외선·적외선, 빈칸이 30 px 이상일 때)
  - 오른쪽 (폭 900 px 이상, 설정 토글): 보어 궤도 $r_n = n^2 a_0$, 처음 궤도 파선·빈 원, 나중 궤도 실선·채운 원 (전자, 파랑), 지름 방향 화살표와 광자
  - 아래: 스펙트럼 띠 (로그 파장축 80 nm ~ 5 µm, 자외선·가시광선 색 막대·적외선). 지금까지 고른 전이의 선 누적, 현재 선 굵게 + 아래 삼각 표시, 범위 밖 선은 끝의 삼각형
  - 띠 오른쪽 위 "지우기" 버튼 (현재 선 말고 모은 선이 있을 때만): 한 번 탭/클릭 (`Handle.onTap`)으로 모은 선 삭제, 현재 전이의 선만 남김. 버튼 자리는 늘 비워 둬 영역 이름이 움직이지 않음
  - 방출: 어두운 띠 위 밝은 선, 흡수: 연속 스펙트럼 위 검은 선. 가시광선 밖 선은 파선
  - 처음 $n_i$, 나중 $n_f$ (주, 스테퍼): 1–10, 기본 3 → 2 ($\text{H}_\alpha$, 656.5 nm). 계열 (설정): 없음·라이먼·발머·파셴·브래킷 → 계열 선 40개 흐리게 + 계열 한계 파선 + 괄호와 이름. 보어 궤도 (설정 토글, 기본 켬)
  - 도표 조작: 화살표 양 끝 손잡이 (꼬리 = $n_i$, 촉 = $n_f$)를 위아래로 끌면 가장 가까운 준위에 맞춤 (확대 그림 안에서도), 한쪽 손잡이 두 번 탭 → $n_i \leftrightarrow n_f$ (방출 ↔ 흡수). 잡는 반지름 16 px (이전 14 px)
  - 수치 줄: $\lambda$, $\Delta E$
  - Σ: $E_n$ 값, $\Delta E = 13.60(1/n_\text{low}^2 - 1/n_\text{high}^2)$ eV, $\lambda = hc/\Delta E$, $1/\lambda = R_\text{H}(\dots)$
- 탭 2 스펙트럼 계열 (시간 장면, 시계 숨김)
  - 계열 (주): 라이먼·발머 (기본)·파셴·브래킷. 과정 (주): 방출·흡수
  - 재생: 0.7 s마다 다음 전이 ($n = n_\text{low} + 1$부터 12개), 화살표가 왼쪽에서 오른쪽으로 늘어서고 (Halliday 그림 형식) 스펙트럼 띠에 선 누적, 계열 한계 파선에 접근. 마지막 선 뒤 자동 정지
  - 수치 줄: $n$, $\lambda$, $\lambda_\infty$. Σ: $1/\lambda = R_\text{H}(1/n_\text{low}^2 - 1/n^2)$, 현재 $\lambda$, $\lambda_\infty = n_\text{low}^2/R_\text{H}$
- 검증 (테스트)
  - 공기 중 발머: $\text{H}_\alpha$ 656.28, $\text{H}_\beta$ 486.13, $\text{H}_\gamma$ 434.05, $\text{H}_\delta$ 410.17 nm (NIST와 0.02 nm 이내, 교재 값 656.3·486.1·434.0·410.2 nm)
  - 진공: $\text{H}_\alpha$ 656.47 nm, 라이먼 $\alpha$ 121.57 nm (자외선), 파셴 $\alpha$ 1875.6 nm (적외선)
  - 계열 한계 (진공): 91.18·364.70·820.59·1458.8 nm
  - 부호: 속박 준위 모두 음수, $n$ 증가 → 0으로 증가, 방출 시 원자 에너지 변화 음수·광자 에너지 양수
- 화면 문구: 축·준위 라벨, 영역 이름, 계열 이름, 지우기 버튼만. 축 방식·끌기 조작·지우기 동작·진공 파장·환산 질량·로그축·보어 모형 한계는 ⓘ
- 테스트 추가 (2차 검토): 손잡이 잡는 반지름 ≥ 14 px, 손잡이 위치 = 화살표 끝 (가까운 준위면 왼쪽으로 비킴), 지우기 버튼 표시 조건·삭제 후 현재 선만 남음·$n_i = n_f$이면 모두 삭제, 버튼이 화면 안·영역 이름과 겹치지 않음

### 6.3 퍼텐셜 우물: 전이 (→ Ch 39)

- **학습 목표**: 우물 속 전자의 두 준위 사이 전이 → 광자 파장 $\lambda = hc/\Delta E$, 폭이 색을 정함 ($\lambda \propto L^2$)
- 경로 `#/ch/103`, 코드 `src/sims/review/welljump/`. Ch 39 탭은 그대로 두고 검토 페이지로 먼저 공개
- 물리: 1차원 무한 우물 전자, $E_n = n^2h^2/(8mL^2)$ (해석해). Ch 39 솔버 (`wellModel`, `eigen.solve`)와 일치 테스트. 스펙트럼 띠·광자 그리기는 6.2와 공유 (`hydrogen/spectrum.ts`)
- 화면
  - 왼쪽: 우물 (벽 주황, 바깥 음영), 준위 $n = 1$–5 위에 $\psi_n$ 또는 $\lvert\psi_n\rvert^2$ (Ch 39 형식, 같은 높이). 전이의 두 상태 진하게, 나머지 흐리게
  - 가운데: 준위 사다리 + 전이 화살표 + 광자 (6.2와 같은 규칙), 오른쪽에 $E_n$ 값. 화살표 양 끝 끌기 손잡이는 6.2와 같은 그림 (`hydrogen/stage.ts` 공유)
  - 아래: 스펙트럼 띠 (로그 파장축 5 nm ~ 5 µm, X선 10 nm 미만). 고른 전이의 선 누적, 폭을 바꾸면 모든 선이 함께 이동. 띠 오른쪽 위 "지우기" 버튼 (6.2와 같음)
- 두 축 모두 $L$에 맞춤: $x$는 $\pm 0.62\,L$, 에너지축은 $27.5\,E_1$까지 → 그림 모양은 일정, 눈금·값·광자 색만 변함 (ⓘ에 기재)
- 조작
  - 우물 폭 (주, 로그 슬라이더): 0.2–2 nm, 유효숫자 2자리, 기본 1.0 nm ($E_1$ = 0.376 eV). 표시 (주): $\psi$ / $\lvert\psi\rvert^2$
  - 처음 $n_i$, 나중 $n_f$ (설정, 스테퍼 1–5, 기본 3 → 2: 659 nm 빨강). 사다리 위 화살표 끝 손잡이 끌기·두 번 탭 (6.2와 같음, 잡는 반지름 16 px)
  - 수치 줄: $E_1$, $\Delta E$, $\lambda$
  - Σ: $E_1 = (hc)^2/(8\,mc^2L^2)$ 대입, $E_n = n^2E_1$ 값, $\Delta E = (n_\text{high}^2 - n_\text{low}^2)E_1$, $\lambda = hc/\Delta E$
- 검증 (테스트): $L$ = 200 pm → $E_1$ = 9.40 eV, $2 \to 1$ 28.2 eV·44.0 nm (자외선). $L$ = 1 nm → $3 \to 2$ 1.880 eV·659.4 nm (가시광선), $2 \to 1$ 1099 nm (적외선). $E_n \propto n^2$, $\lambda \propto L^2$, $\psi_n$ 규격화·마디 $n - 1$개
- ⓘ: 전기 쌍극자 선택 규칙 ($n_i - n_f$ 홀수만 허용, $3 \to 1$ 금지)은 설명만, 화면은 교재 문제처럼 모든 쌍에 광자 표시
- 유한 우물은 제외: 폭 범위 (0.2–2 nm)에서 속박 상태 수와 축 범위가 크게 바뀌어 별도 설계 필요

### 6.4 내적과 외적 (→ Ch 3)

- **학습 목표**: 내적 = 크기 × 정사영 ($a\,(b\cos\varphi)$), 외적의 크기 = 평행사변형 넓이 = 밑변 × 높이 ($a\,\lvert b\sin\varphi\rvert$), 방향 = 오른손 규칙. 크기·각 계산과 성분 계산의 일치
- 경로 `#/ch/104`, 탭 2개 (내적 / 외적). 정적 장면, 플롯 열 없음 → 스테이지 안 그래프
- 공통 화면
  - Ch 3과 같은 벡터 평면: 단위 격자, $x$·$y$ 축, $\vec a$ 파랑, $\vec b$ 주황, 끝 드래그 손잡이 (옅은 원)
  - 끌기 방식 드롭다운: 부드럽게 / 0.5 간격 맞춤. 벡터 길이 상한 (내적 5, 외적 4.5), 저장값 소수 둘째 자리
  - 사잇각 호와 $\varphi$ 값, 화살표 옆 $a$, $b$ 값. 라벨끼리·화살표·축·축 이름·눈금 숫자와 겹치지 않는 자리 선택, 자리가 없으면 가까운 빈자리 탐색 → 그래도 없으면 값만 표시
  - 격자 한 칸 = 길이 1 (임의 단위) → $a$, $b$, 정사영, 높이 = 길이, 곱 = (길이 단위)² (ⓘ 가정)
  - 그래프: 넓은 화면은 평면 오른쪽, 좁은 화면은 평면 아래. $\varphi$만 바뀔 때의 곱 (검은 선)과 인수 (정사영 또는 높이, 평면의 띠와 같은 색 반투명 굵은 선), 같은 수치 눈금 → 검은 막대 = 주황 막대의 $a$배
  - 현재 $\varphi$: 0에서 곱까지 검은 막대 + 점, 0에서 인수까지 반투명 막대 + 작은 점, 막대 끝마다 이름과 값 (예: $\vec a\cdot\vec b$ = 7.00, $b\cos\varphi$ = 1.70). 그래프 안, 곡선·막대와 겹치지 않는 자리, 좁으면 값만
  - 점 드래그 → $\vec b$ 회전 (길이 유지). y 범위 = $ab$와 $b$ 중 큰 값 이상의 깔끔한 수
  - 값 표시 줄: $\varphi$, 곱
- 탭 1 내적
  - 정사영 드롭다운: $\vec b$ → $\vec a$ 방향 / $\vec a$ → $\vec b$ 방향
  - $\vec a$ (또는 $\vec b$) 방향의 연장선 (점선), 다른 벡터 끝에서 내린 수선, 직각 표시, 정사영 = 같은 색 굵은 반투명 띠 (끝이 각진 띠, 길이 = 정사영 길이), 라벨 $b\cos\varphi$ = 값 (부호 포함)
  - $\varphi > 90^\circ$: 정사영이 원점 뒤쪽 연장선 위 → 음수 내적
  - 그래프: $0$–$180^\circ$, $ab\cos\varphi$와 $b\cos\varphi$
  - **곱 직사각형** (그래프 오른쪽, 좁은 화면은 그래프 옆): 가로 = $a$ (파랑 선), 세로 = $b\cos\varphi$ (평면과 같은 주황 띠), 넓이 = $\vec a\cdot\vec b$, 안에 $\vec a\cdot\vec b$ = 값. 고정 축척 (길이 5까지 칸 안), 음수면 기준선 아래 + 빗금
  - "$\vec a$ → $\vec b$ 방향"이면 역할 교대: 가로 $b$ (주황), 세로 $a\cos\varphi$ (파랑 띠)
  - Σ 패널 4줄: $\vec a\cdot\vec b = a\,(b\cos\varphi) = a_x b_x + a_y b_y$ / $b\cos\varphi = (3.16)\cos 57.5^\circ = 1.70$ / $a\,(b\cos\varphi) = (4.12)(1.70) = 7.00$ / 성분 대입 = 7.00
- 탭 2 외적
  - 평행사변형 (옅은 회색 채움, 맞은편 두 변 = 옮긴 $\vec a$, $\vec b$ 점선), $\vec a$ 방향 연장선 (점선)
  - 높이 $b\sin\varphi$: $\vec b$ 끝에서 $\vec a$ 연장선에 내린 수선 = 주황 반투명 띠 (발 F에 직각 표시), 라벨 $b\sin\varphi$ = 값 (부호 포함, $\otimes$이면 음수)
  - **넓이가 같은 직사각형** (검은 점선): 꼭짓점 F, F + $\vec a$, $\vec a + \vec b$, $\vec b$. 삼각형 O·F·$\vec b$를 잘라 $\vec a$만큼 옮긴 모양 → 밑변 $a$, 높이 $\lvert b\sin\varphi\rvert$, 윗변 = 평행사변형 윗변
  - 평행사변형 가운데 $\odot$ (종이 면에서 나옴, $\vec b$가 $\vec a$에서 반시계 방향) / $\otimes$ (들어감, 시계 방향), 옆에 $\lvert\vec a\times\vec b\rvert$ = 넓이 값. 평행·반평행이면 기호 없음
  - 사잇각 호 끝 화살촉 = $\vec a$에서 $\vec b$로 감는 방향. $\varphi$ = 부호 있는 각 ($-180^\circ$–$180^\circ$, 반시계 양수)
  - 그래프: $-180^\circ$–$180^\circ$, $(\vec a\times\vec b)_z = ab\sin\varphi$와 $b\sin\varphi$, 양의 봉우리 안 $\odot$, 음의 골 안 $\otimes$ (두 곡선 중 낮은 쪽 높이의 절반)
  - Σ 패널 5줄: $(\vec a\times\vec b)_z = a\,(b\sin\varphi) = a_x b_y - a_y b_x$ / $b\sin\varphi = (3.16)\sin(57.5^\circ) = 2.67$ / $a\,(b\sin\varphi) = (4.12)(2.67) = 11.0$ / 성분 대입 = 11.0 / 방향 $\pm\hat k$
- 기본값: $\vec a = (4, 1)$, $\vec b = (1, 3)$ → $\varphi = 57.5^\circ$, $\vec a\cdot\vec b = 7$, $b\cos\varphi = 1.70$, $(\vec a\times\vec b)_z = 11$, $b\sin\varphi = 2.67$
- 테스트
  - 무작위 벡터에서 성분식 = 크기·각 식 (상대 오차 $10^{-12}$), 수직 → 내적 0, 평행 → 외적 0, $\hat x\times\hat y = +\hat k$, $\vec b\times\vec a = -\vec a\times\vec b$, 내적 부호 ↔ $\varphi \lessgtr 90^\circ$, 신발끈 공식 넓이 = $\lvert\vec a\times\vec b\rvert$
  - 인수분해: $a\,(b\cos\varphi) = \vec a\cdot\vec b$, $a\,(b\sin\varphi) = (\vec a\times\vec b)_z$, 직사각형 F, F + $\vec a$, $\vec a + \vec b$, $\vec b$의 부호 있는 넓이 = $(\vec a\times\vec b)_z$ ($10^{-9}$)
  - 그려진 도형 (기록용 Draw, 넓은·좁은 화면, $\varphi$ 15° 간격 × 크기 5조): 그래프 막대 = 곱·인수, 곱 막대 = $a$ × 인수 막대, 평면 띠 길이 = 정사영·높이, 곱 직사각형 넓이 = $\vec a\cdot\vec b$ ($10^{-9}$), 음수 ↔ 기준선 아래 + 빗금
  - 라벨: 겹침 없음, 스테이지 밖 없음, 곱과 인수 값이 화면에 있음

### 6.5 평형과 탄성: 사다리의 평형과 미끄러짐 (→ Ch 12)

- **학습 목표**: 정적 평형 조건 $\sum\vec F = 0$, $\sum\vec\tau = 0$. 회전축 선택 (사다리 발 → $N$, $f$ 소거), 필요한 마찰력과 최대 정지 마찰력 비교, 한계를 넘은 뒤의 미끄러짐 (운동 마찰, 뉴턴 제2법칙)
- 경로 `#/ch/105`, 페이지 제목 "평형과 탄성", 탭 1개 "평형과 미끄러짐". 시간 장면 (재생 전 = 정적 평형 화면), 그래프 없음
- 2차 검토 반영 (사용자 피드백: 사람이 올라가다 미끄러지는 시뮬레이션, 사람 대신 단순한 도식)
  - 막대 인형 → 사다리 위 점질량: 사다리 축 위 위치 $d$에 중심을 둔 원, 안에 $M$
  - 재생: $M$이 속력 $v$로 오름 → $d = d_c$에서 미끄러지기 시작 → 위 끝이 벽에서 떨어지는 순간 ($F_w = 0$)에서 종료
  - 그래프 ($\theta(t)$, $f/\mu_s N$)는 시험 후 제외: 좁은 화면에서 무대가 화면 높이 30 %로 줄어 라벨 겹침. 막대의 ▾ 표시·값 표시 줄·Σ 패널로 대신함
- 화면
  - 마찰 없는 벽 (오른쪽), 거친 바닥, 균일한 사다리 ($L$ = 5 m, 두 레일과 발판), 점질량 $M$ (흰 원, 검은 테두리)
  - 사다리 위쪽 치수선: 발 → $M$, 라벨 $d$
  - 힘 (자주색 계열, 라벨로 구분): $mg$ (사다리 가운데에서 아래로), $Mg$ (화살표 끝 = 원 위쪽, 작용선은 $M$ 중심), $N$ (발에서 위로), $f$ (발에서 벽 쪽으로), $F_w$ (위 끝에서 벽 반대쪽으로). $N$, $F_w$는 짙은 자주
  - 화살표 길이 ∝ 힘 (400 N = 1 m, 시작 상태의 가장 긴 화살표가 2.2 m를 넘으면 전체 축소, 실행 중 고정)
  - 지레팔 (발 기준) 치수선: 바닥 아래 $(L/2)\cos\theta$, $d\cos\theta$, 발 왼쪽 $L\sin\theta$. 미끄러지는 동안 현재 사다리를 따라감
  - 왼쪽 위 막대: $f/\mu_s N$ (%). 오르는 동안 $d$에 비례해 증가, $d_c$에서 100 %. 미끄러지는 동안 $\mu_k/\mu_s$ (기본 80 %), 100 % 위치에 ▾ 표시 유지
  - 시작 위치가 $d_c$보다 높으면 (재생 전): 마찰 화살표는 $\mu_s N$에서 멈춤, 필요한 나머지는 점선, 막대 100 % 초과 (점선 칸, 값 굵게)
  - 미끄러지는 동안: 바닥에 미끄러지기 전 발 위치 눈금. 종료 시 위 끝에 빈 원, 라벨 $F_w = 0$
  - 한계 표시 (설정, 기본 켜짐): 현재 $d$에서의 임계각 $\theta_c$ 사다리 (회색 점선, 오를수록 실제 사다리에 접근, $d_c$에서 일치), 시작 각에서의 임계 위치 $d_c$ 막대
  - 라벨: 화살표·치수선·사다리와 겹치지 않는 후보 자리 중 첫 번째 (Ch 3 배치 모듈)
  - 자유물체도 토글 없음: 힘이 작용점마다 이미 핵심 화면. $mg$·$Mg$ 화살표만 파선으로 통일 (떨어져 작용하는 힘)
- 운동 모형
  - 오르기: $d(t) = d_0 + vt$, 매 순간 정적 평형. 미끄러짐 시작 시각 $t_s = (d_c - d_0)/v$ (단계 안에서 정확히 계산)
  - 미끄러짐: 사다리 (균일 막대) + $d_c$에 고정된 $M$ = 강체 하나. 발은 바닥 위, 위 끝은 벽 위, 자유도 $\theta$ 하나
  - 매 순간 연립 1차 방정식: $(m+M)\ddot x_\text{cm} = f - F_w$, $(m+M)\ddot y_\text{cm} = N - (m+M)g$, $I_\text{cm}\ddot\theta = \sum\tau_\text{cm}$, $f = \mu_k N$ → $\ddot\theta$, $N$, $F_w$

  - 위 끝이 벽에서 떨어진 뒤의 2자유도 운동은 계산하지 않음, 실행 종료 (ⓘ에 명시). 슬라이더 범위 전체에서 바닥 도달 전에 항상 $F_w = 0$ 먼저 도달 (378개 조합 확인)

  - 설정: 오르는 속력 $v$ 0.1–1 m/s (0.5), 사다리 질량 $m$ 1–40 kg (10), 사람 질량 $M$ 0–150 kg (70, 0이면 없음), 정지 마찰 계수 $\mu_s$ 0–1 (0.40), 마찰 계수 비 $\mu_k/\mu_s$ 0–0.95 (0.8, 1이면 $d_c$에서 정지 상태 유지), 한계 표시
  - $M$ 끌기 → $d$ 변경, 위 끝 끌기 → $\theta$ 변경. 물리 값 변경 (끌기 포함) → 실행 초기화, 정적 화면
  - 값 표시 줄: $d$, $\theta$, $F_w$, $f/\mu_s N$
- Σ 패널

  - 미끄러지는 동안: $f = \mu_k N$, $F_w$와 $\ddot\theta$, $\theta$·$\dot\theta$·$t - t_s$, 에너지 수지 $E_0 - E = W_f$

  - 압력 $\Delta p = -B\,\partial s/\partial x = \Delta p_m \sin kx\cos\omega t$ (분홍) + 포락선, 아래 $\mathrm{N}_p$·$\mathrm{A}_p$ (분홍). 세로축 라벨 $\Delta p$, $\Delta\rho$ 두 줄: 밀도 변화 $\Delta\rho/\rho = -\partial s/\partial x = \Delta p/B$로 같은 모양
  - 세로 점선: 변위의 마디 = 압력의 배, 관의 고정 기둥 → $\mathrm{N}_s$ → $\mathrm{A}_p$를 잇는 선 (글자는 흰 바탕, 점선이 뒤로 지나감). 열린 끝 = 변위의 배 = 압력의 마디, 닫힌 끝 = 변위의 마디 = 압력의 배
  - 애니메이션은 실제 진동수와 무관하게 2 s에 1주기, 변위는 확대 (ⓘ에 기재)
- 파라미터: 관 (열린 관 / 닫힌 관), 배음 번호 $n$ 스테퍼 (주; 열린 관 1–8, 닫힌 관 1, 3, …, 15 홀수만), 관 길이 0.25–2.00 m (기본 1.00), 소리 토글 (설정, Ch 17 맥놀이의 오디오 모듈로 $f_n$ 순음 재생)

- 수치 줄: $f_n$, $\lambda_n$

- ⓘ: "마디에서 밀도가 변하는 이유" 관찰 항목 (변위의 마디: 움직임 없음, 밀도 변화 최대 = 압력의 배; 변위의 배: 움직임 최대, 밀도 변화 0 = 압력의 마디), 첨자 $s$·$p$와 색의 뜻, 식 $\Delta\rho/\rho = -\partial s/\partial x = \Delta p/B$
