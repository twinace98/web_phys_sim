## 3. 장별 상세 명세

### Part I. 역학

#### Ch 2. Motion Along a Straight Line

- **학습 목표**: 기울기 → 다음 그래프의 값 (미분), 넓이 → 이전 그래프의 변화량 (적분)
- 화면: 상단 1D 트랙 위 물체 · 하단 $x(t)$, $v(t)$, $a(t)$ 세로 정렬 (시간축 공유)
- 탭 1 위치-속도-가속도 그래프: 모드 전환 [미분관계 | 적분관계]
  - 기울기: 시각 커서 $t$에서 $x(t)$ 접선 표시 → 기울기 값이 $v(t)$ 위 점으로 대응. $v \to a$ 동일
  - 넓이: $a(t)$ 아래 $0$–$t$ 구간 음영 → $\Delta v$ 막대로 $v(t)$ 위에 표시. $v \to \Delta x$ 동일
  - 음의 넓이: 별색 음영
- 입력: 프리셋 (등속, 등가속, 출발 후 정지, 왕복) 또는 구간별 상수 $a(t)$ 직접 그리기
- 대안: 단일 화면 구현이 복잡할 경우 미분 / 적분 두 시뮬레이션으로 분할
- 탭 2 자유낙하
  - 세로 스테이지: 공의 낙하, 높이 눈금, 속도·가속도 화살표, 0.1 s 스트로보 점 (떨어뜨리기: 구간 거리 1 : 3 : 5 : …)
  - 던지기 드롭다운: 떨어뜨리기 / 위로 10 m/s / 아래로 10 m/s, 처음 높이 5–45 m (설정)
  - $y(t)$, $v(t)$, $a(t)$ 그래프 + 탭 1과 같은 미분관계·적분관계 표시
  - 착지 순간 자동 정지

#### Ch 3. Vectors

- **학습 목표**: 성분 분해
- 탭 1 성분 분해
  - 2D 평면 + 축 정렬 격자, 축 위 투영 (점선), 성분 화살표, 직각삼각형
  - $\vec A$ 끝 드래그 → 벡터 변경, $A_x$·$A_y$ 끝 드래그 → 해당 성분만 변경
  - 화살표 옆 값 표시: $A$, $A_x$, $A_y$, $\theta$
  - 좌표축 회전 드롭다운 (0–60°): 성분 변화 · 크기 $A$ 불변, 30° = 경사면 좌표 (Ch 5·6 연계)
  - 끌기 방식 드롭다운: 부드럽게 / 0.5 간격 맞춤
- 탭 2 벡터 합: 평행사변형법, $\vec C = \vec A + \vec B$ 대각선
  - 화살표 옆 크기 $A$, $B$, $C$
  - 좌상단 패널: $A_x + B_x = C_x$, $A_y + B_y = C_y$ 기호와 현재 값 (A 파랑, B 주황, C 검정)

#### Ch 4. Motion in Two and Three Dimensions

- **학습 목표**: 포물선 운동 = x 방향 등속운동 + y 방향 등가속운동, 두 성분 독립
- 화면: 궤적 · x축 위 그림자 공 (등속) · y축 위 그림자 공 (연직 투사) 동시 이동
  - 공: 속도 $\vec v$, x 그림자: $v_x$, y 그림자: $v_y$ 화살표
- 일정 시간 간격 스트로보 점: 궤적 위 + 두 축 위 → x 간격 일정, y 간격 선형 변화
- 그래프 4개
  - $x(t)$: 직선
  - $v_x(t)$: 상수
  - $y(t)$: 포물선
  - $v_y(t)$: 기울기 $-g$ 직선
- 발사각 (0–75°)과 발사 높이 (0–40 m)를 독립적으로 조절
  - 높이 $> 0$: 언덕 표시
  - 발사각 0°, 높이 $> 0$ (수평 발사): y 그림자 = 같은 높이에서 떨어뜨린 공 → 착지 시각 동일 (별도 비교 공 대신 그림자로 표현)
- 착지 순간 자동 정지 (체공 시간이 파라미터에 따라 결정)
- 파라미터: 발사각, 발사 높이 (주), $v_0$, $g$ (지구·화성·달), 스트로보 간격, 속도 화살표 (설정)
- 탭 2 등속원운동
  - **학습 목표**: 속력 일정, 속도 방향 변화 → 가속도 존재, $\vec a$는 중심 방향, $a = v^2/r$
  - 화면: 원 궤도 위 점, 접선 방향 $\vec v$, 중심 방향 $\vec a$
  - 속도 원 (설정 토글, 기본 켜짐): 속도 벡터를 한 점에서 그림 → 끝이 원을 따라 움직이는 방향 = $\vec a$, $a = 2\pi v/T = v^2/r$
  - 파라미터: 반지름 1–3 m, 속력 1–3 m/s, 수치 줄 $v$, $a$, $T$
- 탭 3 상대운동 (강 건너기)
  - **학습 목표**: 속도는 기준계에 따라 다름, $\vec v_{BG} = \vec v_{BW} + \vec v_{WG}$
  - 화면: 강폭 20 m, 물살 무늬, 강둑 눈금, 출발점과 맞은편 지점, 배와 지나온 경로
  - 기준계 드롭다운: 지면 기준 (물살 무늬 이동, 배는 $\vec v_{BG}$로 이동) / 물 기준 (강둑이 $-\vec v_{WG}$로 이동, 배는 뱃머리 방향 직진)
  - 벡터 색: Ch 3 벡터 합과 같음 ($\vec v_{BW}$ 파랑, $\vec v_{WG}$ 주황, $\vec v_{BG}$ 검정), 좌상단 패널에 성분식
  - 파라미터: 뱃머리 각 0–60° (주), 배의 속력 1–3 m/s, 물살 0–1.5 m/s (설정)
  - 기본값에서 뱃머리 30° → 물살 상쇄, 맞은편 정면 도착

#### Ch 5. Force and Motion I

- **학습 목표**: 뉴턴 법칙, 관성계
- 탭 1 뉴턴 법칙
  - 1법칙: 마찰 없는 면 위 퍽, 힘 제거 후 등속 유지
  - 2법칙: 힘·질량 선택 → $a = F_\text{net}/m$, $v(t)$ 기울기로 확인
  - 3법칙: 두 수레 서로 밀기 → 힘 크기 동일, 가속도는 질량에 반비례
- 탭 2 관성계
  - 같은 장면 (기차 안 마찰 없는 탁자 위 공)을 지면 / 등속 기차 / 가속 기차 기준계로 전환
  - 등속 기차: 지면과 같은 법칙 성립 (갈릴레이 불변)
  - 가속 기차: 힘 없이 공이 뒤로 가속하는 것으로 관측 → 1법칙 불성립 → 비관성계
  - 관성력 $-m\vec a_\text{frame}$ 표시 토글 (실제 힘과 다른 색·점선)

#### Ch 6. Force and Motion II

- **학습 목표**: 정지/운동 마찰의 차이, 구심력은 새로운 힘이 아님
- 탭 1 마찰
  - 수평면 블록에 가하는 힘 $F$ 선형 증가
  - 그래프 $f(F)$: 정지 구간 $f_s = F$ (필요한 만큼), 최대 $\mu_s N$ 도달 후 $\mu_k N$로 급락
  - 경사각 증가 모드: 미끄러지기 시작하는 각 $\tan\theta_c = \mu_s$
  - 파라미터: 재질 쌍 ($\mu_s$, $\mu_k$) 드롭다운
- 탭 2 원운동
  - 프리셋: 줄에 매단 공 · 평평한 커브 자동차 · 경사 커브 · 원뿔 진자
  - 자유물체도에 실제 힘만 표시 (장력, 중력, 수직항력, 마찰)
  - 알짜힘을 지름·접선 성분으로 분해 → 지름 성분 $= mv^2/r$
  - "구심력" 라벨은 알짜힘의 지름 성분에만 부여, 별도 힘 화살표 없음
  - 줄 끊기 / 마찰 부족: 접선 방향 이탈 → 중심 방향 알짜힘 없이는 원운동 불가

#### Ch 7. Kinetic Energy and Work

- **학습 목표**: 일 = $F(x)$ 그래프 넓이, $W_\text{net} = \Delta K$
- 화면: 상단 블록 이동 · 중단 $F(x)$ 그래프 (넓이 음영) · 하단 $K(x)$ 그래프
- 넓이 누적값과 $K(x) - K_0$ 동시 표시 → 항상 일치
- $F(x)$ 프리셋: 상수, 용수철 $-kx$, 구간별, 사용자 그리기
- 음의 일: 힘과 변위 반대 → 별색 음영, $K$ 감소
- 막대: $W_\text{net}$ vs $\Delta K$

#### Ch 8. Potential Energy and Conservation of Energy

- **학습 목표**: 보존력의 정의 (일이 경로에 무관, 닫힌 경로 일 $= 0$), $F = -dU/dx$
- 탭 1 경로 독립성
  - 2D 평면 위 두 점 A, B. 경로 선택 (직선, 원호, 지그재그, 사용자 그리기)
  - 힘 선택: 중력·용수철 (보존) / 운동마찰 (비보존)
  - 그래프: 경로 따라 누적 일 vs 경로 길이
  - 보존력 → 종점 값 경로 무관 / 마찰 → 경로 길이에 비례
  - 닫힌 경로: 보존력 일 $= 0$, 마찰 일 $< 0$
- 탭 2 에너지 도표
  - $U(x)$ 곡선 + 총에너지 수평선, $K = E - U$ 수직 막대

### Part II. 열역학

#### Ch 18. Temperature, Heat, and the First Law of Thermodynamics

- **학습 목표**: 열과 일의 관계, 1법칙 $\Delta E_\text{int} = Q - W$
- 화면: 피스톤-실린더 + $p$-$V$ 도표
- 과정 선택: 등압 / 등적 / 등온 / 단열
- $p$-$V$ 곡선 아래 넓이 = $W$ 음영
- 막대: $Q$, $W$, $\Delta E_\text{int}$ 실시간 → 등식 성립
- 경로 비교: 같은 시작·끝 상태, 두 경로 → $W$, $Q$ 다름, $\Delta E_\text{int}$ 같음 (상태함수)
- 순환 과정: 순 일 = 순 열 = 닫힌 곡선 내부 넓이

#### Ch 19. The Kinetic Theory of Gases

- **학습 목표**: 작은 입자 충돌의 합 = 압력
- 화면: 2D 상자 안 강체원판 기체. 오른쪽 벽 충돌마다 충격량 $2mv_x$ 표시
- 그래프: 벽에 전달된 충격량의 시간 누적, 이동평균 힘 → 압력으로 수렴
- 비교: 측정 압력 vs 이상기체 예측 (2D: $pA = NkT$)
- 파라미터: 입자 수 $N$, 온도 (평균 속력), 상자 크기
- 관찰: 순간 힘은 요동, 시간평균은 일정. $N$ 증가 → 요동 감소
- 부가: 속력 히스토그램 → 2D 맥스웰-볼츠만 분포로 수렴

#### Ch 20. Entropy and the Second Law of Thermodynamics

- **학습 목표**: 엔트로피 = 거시상태가 허용하는 미시상태 수의 로그, 비가역성의 통계적 기원
- 설명 전략: 통계적 정의 $S = k\ln W$ 우선 → 열역학적 정의 $dS = dQ/T$로 연결
- 탭 1 자유 팽창
  - 칸막이 제거 → 입자의 좌/우 분포
  - 거시상태 $n$ (왼쪽 입자 수), 미시상태 수 $W(n) = \binom{N}{n}$ 막대그래프
  - $N$ 드롭다운: 4, 10, 100, 1000 → 작은 $N$은 모두 왼쪽으로 복귀 관찰 가능, 큰 $N$은 사실상 불가
  - $S(t) = k\ln W$ 그래프, 최대값 근방 요동
- 탭 2 열 흐름 (아인슈타인 고체 두 개)
  - 두 고체 사이 에너지 양자 교환
  - 총 미시상태 수가 커지는 방향 → 고온에서 저온으로 열 흐름
  - $S_A$, $S_B$, $S_\text{tot}$ 그래프 → 평형에서 기울기 일치 → 온도 정의 $1/T = \partial S/\partial E$
- 탭 3 (선택) 카르노 사이클: 효율 상한

#### Ch 23. Gauss' Law

- **학습 목표**: 닫힌 면의 플럭스 = 내부 전하 / $\varepsilon_0$, 외부 전하의 순 기여 0
- 2D 모델: 지면에 수직인 무한 선전하 → 2D 단면에서 가우스 법칙 정확히 성립 ($E \propto 1/r$). 화면 표기 없음, ⓘ 패널에만 기재
- 탭 1 가우스 법칙 (단일 탭)
  - 선전하 $\pm 1$, $\pm 2$ nC/m (종류별 3개) 드래그, 왼쪽 아래 상자로 추가·삭제. 기본: $+2$ 안쪽, $-1$ 바깥
  - 가우스면 드롭다운 (주): 원 (기본) / 정사각형 / 자유 곡선 (조절점 8개, 닫힌 캣멀-롬 곡선)
  - 가운데 점 드래그 → 이동, 테두리 점 → 크기, 자유 곡선 조절점 → 모양
  - 면 위 법선 성분 $E_n$ 화살표: 나가는 방향 주홍, 들어오는 방향 파랑, 길이 선형
  - 좌상단 패널: $\lambda_\text{enc}$, $\oint E_n\,dl$ (적응형 심프슨 수치적분), $\lambda_\text{enc}/\varepsilon_0$ (N·m/C)
  - 표시 드롭다운 (주): 장선 (기본) / 벡터 화살표 / 끄기
  - 특이점 처리: 전하와 면 사이 3.5 cm 이상 유지 (전하는 면 반대쪽으로 밀려남, 면 이동은 건너뜀)
- 관찰
  - 전하가 경계를 넘을 때 플럭스 계단 변화
  - 외부 전하 이동 시 국소 $E_n$은 변화, 총 플럭스는 불변
  - 면 모양·크기를 바꿔도 내부 전하가 같으면 플럭스 동일

#### Ch 24. Electric Potential

- **학습 목표**: 전위, 등전위선 ⊥ 장선, $\vec E = -\nabla V$
- 탭 1 등전위선 (단일 탭)
  - Ch 22 전하 배치·팔레트·배치 프리셋 공유 (기본 쌍극자)
  - 표시 드롭다운 (주): 등전위선 (기본) / 전위 색 지도 (발산형, 주홍 +, 파랑 −, 0 흰색, $\tanh(V/25\,\text{V})$ 압축) / 둘 다
  - 등전위선: 간격 $\Delta V$ 1–10 V 슬라이더 (설정, 기본 5 V), $\lvert V \rvert \le 12\,\Delta V$. 양 주홍, 음 파랑, $V = 0$ 회색 점선
  - 장선 옅게 겹침 (설정 토글, 기본 켜짐) → 등전위선과 장선의 수직 관계
  - 시험전하 경로: 출발점 A와 시험전하 $q_0 = +1$ nC. 시험전하를 끌면 지나온 경로 (주황 점선) 누적, A를 끌면 새 경로
  - 수치 줄: $V$ (시험전하 위치), $\Delta V$ (A 기준), $W$ (경로를 따라 $q_0\vec E\cdot d\vec s$ 수치 적분, nJ)
  - 관찰: 등전위선을 따라 끌면 $W \approx 0$, 가로지르면 $W = -q_0\Delta V$, 경로와 무관. 등전위선 간격이 촘촘할수록 장이 강함

#### Ch 25. Capacitance

- **학습 목표**: $C = \kappa\varepsilon_0 A/d$, 장에 저장되는 에너지

- 핵심 대조: 유전체 삽입 시
  - 전원 연결 ($V$ 일정) → $U$ 증가
  - 전원 분리 ($Q$ 일정) → $U$ 감소

#### Ch 26. Current and Resistance

- **학습 목표**: 전자 산란 → 저항, $R = \rho L/A$
- 화면: 도선 구간 (이온 격자 + 자유전자)
  - 전기장 없음: 무작위 운동, 순 이동 0
  - 전압 인가: 산란 사이 가속 → 평균 드리프트
- 단면 통과 전하 계수 → 전류 $I$ 측정
- 파라미터: 길이 $L$, 단면적 $A$, 온도 (산란 빈도)
- 그래프: $I$ vs $V$ 직선 (옴), $R \propto L$, $R \propto 1/A$
- 드리프트 속도는 과장 표시. 실제 값 (드리프트 ≪ 열속도)은 ⓘ 패널에만 기재

#### Ch 27. Circuits

- **학습 목표**: RC 충·방전의 지수 곡선, 시간상수 $\tau = RC$
- 화면: 회로도 (전지, 스위치, $R$, $C$), 스위치로 충전 / 방전 전환
- 그래프: $V_C(t)$, $I(t)$, $q(t)$. $t = \tau$ 표식 (63 %, 37 %)
- 파라미터: $R$, $C$ 드롭다운
- 관찰: $t = 0$ 접선이 $t = \tau$에서 최종값과 만남, 전류는 처음 최대 → 0

#### Ch 28. Magnetic Fields

- **학습 목표**: 로렌츠 힘 $q\vec v \times \vec B$, 원운동, 주기의 속력 무관성
- 탭 1 균일 자기장 속 하전입자
  - 지면에 수직인 $\vec B$, 입자 발사
  - $\vec v$, $\vec F$ 표시 (항상 수직) → 일 0, 속력 일정
  - $r = mv/(\lvert q\rvert B)$, $T = 2\pi m/(\lvert q\rvert B)$ 실시간
  - 속력이 다른 입자 동시 발사 → 반경 다름, 한 바퀴 시간 같음
  - 파라미터: 입자 (전자, 양성자, 알파 입자), $B$, $v$
- 탭 2 사이클로트론 가속기
  - 두 D자 전극, 틈에서 교류 전기장 가속 → 나선 궤적
  - 교류 주파수 = 사이클로트론 주파수일 때만 가속 지속

#### Ch 29. Magnetic Fields Due to Currents

- **학습 목표**: 비오-사바르 법칙 (전류 요소 기여의 합), 앙페르 법칙 (닫힌 경로 순환 = 관통 전류)
- 탭 1 비오-사바르 법칙
  - 도선 드롭다운 (주): 직선 도선 (길이 2.2 m, 기본) / 원형 고리 ($R = 0.45$ m), 전류 $I = 10$ A
  - 전류 요소 수 (주): 4–48 슬라이더 (기본 24). 4 s 동안 요소를 하나씩 합산, 합산된 부분은 검정, 현재 요소 $d\vec l$ (파랑)과 $\vec r$ (점선)
  - 관측점 $P$ 드래그 (도선에서 6 cm 이상, 이동 시 처음부터): $P$에 누적 $B$ (⊙ / ⊗, 검정)와 현재 요소의 $dB$ (파랑 작은 기호)
  - 그래프: $dB(t)$ (요소별 기여), $B(t) = \sum dB$ + 기준 점선 ($\mu_0 I/2\pi d$ 또는 고리 중심 $\mu_0 I/2R$)
  - 수치 줄: $B$ (누적), $d$ (도선 또는 고리 중심까지 거리)
- 탭 2 앙페르 법칙
  - 지면에 수직인 도선 (⊙, ⊗ 각 1 A, 종류별 16개) 드래그, 왼쪽 아래 상자로 추가·삭제
  - 배치 (주): 단일 도선, 반대 방향 쌍 (기본), 솔레노이드 단면 (두 줄 16개씩, 간격 8 cm). 배치마다 고리 처음 위치 따로 (솔레노이드: 위쪽 줄 4개를 감쌈)
  - 앙페르 고리 (주): 원 / 정사각형 / 자유 곡선, Ch 23과 같은 조작
  - 고리 위 접선 성분 $B_t$ 화살표 (경로 방향 주홍, 반대 방향 파랑)
  - 좌상단 패널: $I_\text{enc}$, $\oint \vec B\cdot d\vec l$ (수치 적분), $\mu_0 I_\text{enc}$ (μT·m)
  - 표시 (설정): 자기력선 (기본, 흐름함수 $A_z$ 등고선 → 선 밀도 ∝ $B$) / 벡터 화살표 / 끄기
  - 솔레노이드 단면: 안쪽 거의 균일하고 강함, 바깥 약함

#### Ch 30. Induction and Inductance

- **학습 목표**: 패러데이·렌츠 법칙, 맥스웰 방정식 네 개 각각의 의미
- 배치 메모: 교재상 맥스웰 방정식은 Ch 32. 본 프로젝트는 유도 법칙과 묶어 Ch 30에서 종합, Ch 32는 자성에 집중
- 탭 1 패러데이·렌츠
  - 사각 루프가 자기장 영역 통과, 또는 자석 접근
  - 그래프: $\Phi_B(t)$, $\mathcal{E}(t) = -d\Phi_B/dt$ (Ch 2 기울기 표시 재사용)
  - 유도전류 방향 + 유도전류가 만드는 자기장 → 플럭스 변화를 방해하는 방향
- 탭 2 맥스웰 방정식 (방정식별 미니 장면)
  - 가우스 (전기): 닫힌 면 전기 플럭스 = 내부 전하 (Ch 23 재사용)
  - 가우스 (자기): 자석 장선은 닫힌 고리 → 어떤 닫힌 면이든 순 자기 플럭스 0, 홀극 부재
  - 패러데이: 변화하는 자기장 → 회전하는 (비보존) 전기장
  - 앙페르-맥스웰: 충전 중 축전기. 도선을 지나는 면 vs 판 사이를 지나는 면 → 변위전류 포함 시 같은 결과
  - 각 장면: 적분형 수식 + 한 줄 의미 + 측정 수치

#### Ch 31. Electromagnetic Oscillations and Alternating Current

- **학습 목표**: RLC 진동, 전압과 전류 사이 위상차의 원인
- 탭 1 자유 진동
  - LC: 전기 에너지 ↔ 자기 에너지 교환, Ch 15 용수철 대응표 병기
  - $R$ 추가 → 감쇠
- 탭 2 교류 구동
  - 그래프: $i(t)$, $v_R(t)$, $v_L(t)$, $v_C(t)$ 겹쳐 표시
  - 위상차의 원인
    - $v_R = iR$ → 동위상
    - $v_C = q/C$, $q = \int i\,dt$ → 사인의 적분 → $90^\circ$ 뒤짐 (전하 축적에 시간 필요)
    - $v_L = L\,di/dt$ → 사인의 미분 → $90^\circ$ 앞섬
    - Ch 2 기울기·넓이 표시 재사용
  - 회전 위상자 다이어그램, 투영 = 순간값 (Ch 15 원운동 투영 재사용)
  - 구동 주파수 스윕 → 공명 곡선, $\omega_0 = 1/\sqrt{LC}$에서 $v_L + v_C = 0$

#### Ch 32. Maxwell's Equations; Magnetism of Matter

- **학습 목표**: 자성의 기원 (전자의 궤도·스핀 자기모멘트), 스핀 정렬과 자화
- 형식주의 (이징 모형 해밀토니안) 비노출. 내부 구현만 이웃 정렬 규칙 + 열적 요동
- 탭 1 기원: 원운동 전자 = 전류 고리 = 자기쌍극자, 스핀 자기모멘트 개념도
- 탭 2 물질 비교 (화살표 격자)
  - 상자성: 독립 모멘트, 외부 $B$와 온도의 경쟁 → 부분 정렬, $B$ 제거 시 무질서 복귀
  - 강자성: 이웃끼리 정렬 경향 → 자구 형성, 외부 $B$로 자구 벽 이동, 제거 후 잔류 자화
  - 반자성: 외부 $B$와 반대 방향 유도 모멘트 (Ch 30 렌츠 연계), 약함
- 그래프: 자화 $M$ vs 외부 $B$ → 강자성 히스테리시스 고리
- 온도 슬라이더: 고온에서 강자성 → 상자성 (퀴리 온도, 정성적)

#### Ch 33. Electromagnetic Waves

- **학습 목표**: 말뤼스 법칙, 굴절, 전반사와 임계각
- 탭 1 편광
  - 비편광 → 편광자 1 → 편광자 2 (각도 다이얼), 구간별 $\vec E$ 진동 방향 표시
  - $I = I_0\cos^2\theta$ 그래프 + 현재 값
  - 3편광자 모드: 교차 편광자 사이 $45^\circ$ 편광자 삽입 → 빛 통과
- 탭 2 굴절·전반사
  - 두 매질 경계, 입사각 드래그
  - 반사·굴절 광선 실시간 ($n_1\sin\theta_1 = n_2\sin\theta_2$), 세기 비율은 선 굵기
  - 고굴절 → 저굴절 매질: 임계각에서 굴절각 $90^\circ$, 이후 전반사
  - 매질 드롭다운: 공기, 물, 유리, 다이아몬드 → 임계각 수치
  - 응용 프리셋: 광섬유

### Part IV. 광학

#### Ch 34. Images

- **학습 목표**: 거울·렌즈의 상 작도, 실상·허상
- 광학대: 볼록/오목 렌즈, 오목/볼록 거울, 평면거울
- 물체 드래그 → 주요 광선 3개 자동 작도, 상 위치·크기
- 수치: $1/p + 1/i = 1/f$, 배율 $m$, 실상/허상·정립/도립
- 초점 안쪽 물체 → 허상 전환 관찰
- 부가: 두 렌즈 조합 (현미경·망원경 원리)

#### Ch 35. Interference

- **학습 목표**: 이중슬릿 간섭, 경로차와 무늬
- 화면: 왼쪽 평면파 → 이중슬릿 → 2D 파동 전파 애니메이션 → 오른쪽 스크린
- 스크린 기록: 시간평균 세기 누적 → 밝기 띠 + 세기 그래프 형성 과정
- 파라미터: 슬릿 간격 $d$, 파장 $\lambda$, 스크린 거리 $D$
- 스크린 점 클릭 → 두 슬릿까지 경로 표시, $\Delta L/\lambda$ 수치
- 무늬 간격 $\Delta y = \lambda D/d$ 비교
- 부가: 입자 하나씩 기록 모드 (Ch 38 연계)

#### Ch 36. Diffraction

- **학습 목표**: 단일슬릿 회절의 원인 (슬릿 내부 호이겐스 점원들의 간섭)
- 화면: 슬릿 폭 조절 → 2D 파동 전파 → 스크린 세기
- 원인 설명 레이어
  - 슬릿을 점원 $N$개로 분할 표시
  - 첫 극소: 슬릿 위·아래 절반의 대응 점원 쌍 경로차 $\lambda/2$ → 상쇄 → $a\sin\theta = \lambda$
  - 위상자 사슬: 각도 증가 → 화살표 사슬이 말려 원 → 합 0 (극소)
- 파라미터: 슬릿 폭 $a$, 파장
- 관찰: $a$ 감소 → 중앙 극대 확산. $a \gg \lambda$ → 기하광학 그림자
- 부가: 이중슬릿 = 간섭 × 회절 포락선

### Part V. 현대물리

#### Ch 37. Relativity

- **학습 목표**: 시간 팽창·길이 수축의 상호성, 두 관측자 시점 동시 비교
- 화면 분할: 좌측 S (지면) 기준, 우측 S' (우주선) 기준. 같은 사건들을 각 기준에서 동시 재생
- 빛 시계: 각 기준계에 하나씩
  - 자기 시계: 수직 왕복
  - 상대 시계: 지그재그 경로 → 느리게 감 (양쪽 모두 상대 시계가 느림)
- 막대: 각 계의 고유 길이 막대 → 상대 계에서 수축
- 시공간 도표: S 직교축 + S' 기울어진 축 겹침. 사건 클릭 → 두 좌표 읽기, 동시선 표시
- 동시성의 상대성: 기차 중앙 섬광 → 양 끝 도달 사건의 동시 여부가 기준계마다 다름
- 파라미터: $\beta = v/c$ (0.1–0.99), $\gamma$ 표시

#### Ch 38. Photons and Matter Waves

- **학습 목표**: 파속이 입자처럼 행동, 드브로이 파장
- 탭 1 파속
  - 평면파 성분 수 증가 → 국소화된 파속 형성 ($\Delta x\,\Delta k$ 관계)
  - $\mathrm{Re}\,\psi$, $\lvert\psi\rvert^2$ 이동 → 군속도 = 입자 속도
  - 고전 입자 점과 동시 이동 비교
- 탭 2 드브로이 파장
  - 입자 선택 (전자, 중성자, $\text{C}_{60}$ 분자, 야구공) + 속력·에너지 → $\lambda = h/p$
  - 입자 그림 위 파동 겹쳐 표시, 크기 기준 막대 (원자 간격, 슬릿 폭 등)
  - 야구공 (0.145 kg, 40 m/s): $\lambda \approx 10^{-34}$ m → 파동성 관측 불가
- 부가: 전자 하나씩 이중슬릿 누적 (Ch 35 엔진)

#### Ch 39. More About Matter Waves

- **학습 목표**: 갇힘 → 에너지 양자화
- 퍼텐셜 선택: 무한 우물, 유한 우물, 조화 퍼텐셜, 이중 우물
- 화면: $U(x)$ + 에너지 준위 수평선 + 각 준위 위 $\psi_n$ 또는 $\lvert\psi_n\rvert^2$ (Ch 8 에너지 도표 형식)
- 파라미터: 우물 폭, 깊이, 장벽 높이·폭
- 관찰
  - 무한 우물: $E_n \propto n^2$, 폭 감소 → 준위 간격 증가
  - 유한 우물: 벽 바깥 지수 감쇠 침투 (고전 금지 영역), 속박 상태 수 유한
  - 조화: 등간격 $\hbar\omega$, 바닥상태 $\hbar\omega/2$ (Ch 15 연계)
  - 이중 우물: 준위 쌍 분리 (결합·반결합) → Ch 41 띠 형성의 출발점
- 부가: 두 고유상태 중첩의 시간전개 (진동하는 확률밀도)

#### Ch 40. All About Atoms

- **학습 목표**: 스핀 양자화, 측정 축 의존성
- 화면: 원자 빔 → 슈테른-게를라흐 (SG) 자석 (축 선택) → 스크린
- 단일 장치: 고전 예측 (연속 띠) vs 실제 (두 점) 토글
- 연속 장치: SG-z → (위 빔만) → SG-x → (위 빔만) → SG-z
  - 마지막 단계에서 아래 성분 재등장 → x 측정이 z 정보 소거
- 축 각도 $\theta$ 자유 선택 → 확률 $\cos^2(\theta/2)$, 원자 하나씩 누적 계수 vs 이론값
- 파라미터: 장치별 축, 통과 빔 선택, 원자 수

#### Ch 41. Conduction of Electricity in Solids

- **학습 목표**: 밴드갭에 따른 금속/반도체/절연체 구분, 금속의 전도 원리, 반도체의 특성
- 탭 1 띠 형성: 우물 1 → 2 → $N$개 → 준위가 띠로 확장, 띠 사이 간격 = 밴드갭 (Ch 39 엔진)
- 탭 2 채움과 분류
  - 띠 그림 + 전자 채움 (페르미 준위)
  - 금속: 부분적으로 찬 띠
  - 절연체: 꽉 찬 띠 + 큰 갭 (수 eV)
  - 반도체: 작은 갭 (약 1 eV)
  - 온도 슬라이더 → 페르미-디랙 분포 → 전도띠 전자·원자가띠 정공 생성 ($\propto e^{-E_\text{g}/2kT}$)
- 탭 3 전도 원리
  - $E(k)$ 띠에 전자 점유 표시, 전기장 인가 → 점유 분포 이동
  - 부분 찬 띠: 순 운동량 ≠ 0 → 전류 / 꽉 찬 띠: 같은 분포 유지 → 전류 0
- 탭 4 도핑: n형 (주개 준위), p형 (받개 준위), 온도별 캐리어 농도

#### Ch 42. Nuclear Physics

- **학습 목표**: 확률적 붕괴 → 지수 법칙, 반감기
- 화면: 핵 격자 ($N_0$개), 시간 단계마다 각 핵이 독립 확률로 붕괴 (색 변화)
- 그래프: $N(t)$ 계단 곡선 + $N_0 e^{-\lambda t}$, 반감기 표식 ($N_0/2$, $N_0/4$, ...)
- $N_0$ 드롭다운: 10, 100, 10000 → 작은 수에서 요동, 큰 수에서 지수 곡선
- 대조: 개별 핵의 붕괴 시점 예측 불가 / 집단의 반감기 일정
- 동위원소 프리셋: $^{14}\text{C}$, $^{131}\text{I}$, $^{238}\text{U}$ (시간축 자동 축척)
- 부가: 연대 측정 (남은 비율 → 경과 시간)
